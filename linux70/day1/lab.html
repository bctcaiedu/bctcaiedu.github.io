Day 1 · 터미널 첫날

오늘 두 개의 리눅스를 여러분 PC에 만들고, 터미널에서 길을 잃지 않는 법을 배웁니다. 설치가 한 번에 되는 사람은 거의 없습니다. 막히는 게 정상이고, 막힌 지점을 읽어내는 것이 오늘의 진짜 실습입니다.

RULE 1

5분 넘게 혼자 헤매지 않는다

막히면 손을 듭니다. 혼자 30분 쓰는 것보다 손 드는 5초가 낫습니다.

RULE 2

에러 메시지를 먼저 읽는다

지우고 다시 하기 전에 화면에 뜬 영어를 한 번은 읽습니다. 대부분 답이 거기 있습니다.

RULE 3

비밀번호는 화면에 안 보인다

리눅스는 비밀번호를 칠 때 *조차 표시하지 않습니다. 눌리고 있으니 그냥 치고 Enter.

PART 0

시작 전 점검

13:00–13:15

여기서 막히면 오후 내내 막힙니다. 세 가지를 먼저 확인하세요.

CHECK 1

CPU 가상화가 켜져 있는가

  1. Ctrl+Shift+Esc로 작업 관리자를 엽니다.
  2. 성능 탭 → CPU 선택.
  3. 오른쪽 아래 가상화 항목이 사용인지 봅니다.
"사용 안 함"이라면

BIOS에서 가상화(Intel VT-x / AMD-V)를 켜야 합니다. 혼자 하지 말고 지금 손을 드세요. 재부팅이 필요해서 점심시간에 조교와 함께 처리합니다.

CHECK 2

디스크 여유가 60GB 이상인가

파일 탐색기에서 C 드라이브 여유 공간을 확인합니다. 두 개의 리눅스와 앞으로 받을 모델 파일이 들어갈 자리입니다.

CHECK 3

PowerShell이 관리자 권한으로 열리는가

시작 메뉴에서 PowerShell을 찾아 관리자 권한으로 실행을 선택합니다. 창 제목에 관리자가 붙어 있으면 성공입니다.

PART 0 통과 조건

가상화 사용 · 여유 60GB 이상 · 관리자 PowerShell 열림 — 셋 다 되면 다음으로 갑니다.

PART 1

WSL2 설치 — 첫 번째 리눅스

13:15–14:00

윈도우 안에서 도는 진짜 리눅스입니다. 앞으로 10일 중 6일을 여기서 보냅니다.

STEP 1

설치 명령 실행

관리자 PowerShell에서 다음을 칩니다. 설치할 배포판 이름은 강사가 칠판에 적어 준 것을 사용하세요.

# 설치 가능한 배포판 목록 보기
PS> wsl --list --online

# 강사가 지정한 배포판 설치 (예시 — 칠판의 이름으로 바꿀 것)
PS> wsl --install -d Ubuntu-24.04

다운로드에 몇 분 걸립니다. 진행 막대가 멈춘 것처럼 보여도 기다리세요.

재부팅 안내가 뜨면

안내대로 PC를 재부팅합니다. 재부팅 후 우분투 창이 자동으로 뜹니다. 안 뜨면 시작 메뉴에서 Ubuntu를 찾아 실행하세요.

STEP 2

리눅스 계정 만들기

처음 실행하면 계정을 만들라고 합니다. 윈도우 계정과는 완전히 별개입니다.

Enter new UNIX username: namo
New password:
Retype new password:
passwd: password updated successfully
계정 이름 규칙 — 어기면 나중에 반드시 문제가 됩니다
  • 영문 소문자만. 한글·대문자·공백·특수문자 금지
  • 짧게. 앞으로 10일 동안 수백 번 보게 됩니다
  • 비밀번호는 화면에 아무것도 안 보입니다. 정상입니다
  • 비밀번호를 잊으면 곤란합니다. 기억할 수 있는 것으로
STEP 3

제대로 설치됐는지 확인

PowerShell 창(우분투 창 말고)에서 확인합니다.

PS> wsl --list --verbose

  NAME            STATE           VERSION
* Ubuntu-24.04    Running         2
확인

VERSION 열이 2여야 합니다. 1이면 손을 드세요.

이제 우분투 창에서 
$ whoami
namo

$ uname -a
Linux DESKTOP-XXXX 5.15.x-microsoft-standard-WSL2 ... x86_64 GNU/Linux
생각해 보기

uname이 Linux라고 대답했습니다. 여러분은 윈도우 PC 앞에 앉아 있는데 말이죠. 이게 무슨 뜻일까요?

STEP 4

패키지 목록 갱신

갓 설치한 리눅스는 "어떤 프로그램을 받을 수 있는지" 목록이 낡아 있습니다. 갱신합니다.

$ sudo apt update
[sudo] password for namo:   ← STEP 2에서 만든 비밀번호. 안 보이는 게 정상
Hit:1 http://archive.ubuntu.com/ubuntu noble InRelease
...
All packages are up to date.

$ sudo apt upgrade -y

sudo는 "관리자 권한으로 실행"이라는 뜻입니다. Day 4에서 자세히 다룹니다. 지금은 "설치·변경에는 sudo가 붙는다" 정도로 넘어갑니다.

여기서 멈추거나 에러가 나면

학교 네트워크 문제일 수 있습니다. 혼자 재시도하지 말고 손을 드세요.

PART 1 통과 조건

wsl --list --verbose의 VERSION이 2 · whoami가 내 계정 출력 · sudo apt update 정상 완료

PART 2

가상머신 — 두 번째 리눅스

14:10–15:00

이번엔 화면 없는 서버입니다. 계정·방화벽·재부팅처럼 WSL2에서 못 해 보는 실험을 여기서 하고, 망가지면 스냅샷으로 되돌립니다.

STEP 1

VirtualBox 설치

공유 폴더의 설치 파일을 실행하고 기본값으로 진행합니다. 중간에 네트워크가 잠깐 끊긴다는 경고가 나오는데 정상입니다.

STEP 2

가상머신 만들기

새로 만들기를 누르고 아래 값으로 설정합니다.

항목값이유
이름ubuntu-server영문으로. 한글 이름은 경로 문제를 일으킵니다
종류 / 버전Linux / Ubuntu (64-bit)64비트가 안 보이면 가상화가 꺼진 것입니다
메모리4096 MB내 PC RAM의 절반을 넘기지 마세요
프로세서2 CPU설정 → 시스템 → 프로세서에서
디스크25 GB (동적 할당)실제로는 쓴 만큼만 차지합니다
STEP 3

ISO 넣고 부팅

  1. 만든 VM 선택 → 설정 → 저장소.
  2. 비어 있는 광학 드라이브를 클릭 → 오른쪽 디스크 아이콘 → 공유 폴더의 우분투 서버 ISO 선택.
  3. 시작을 눌러 부팅.
STEP 4

우분투 서버 설치

파란 화면의 설치 마법사가 뜹니다. 마우스가 안 되는 게 정상입니다 — Tab과 화살표, Enter, Space로 움직입니다.

  1. 언어 English — 에러 메시지를 검색하기 쉬워집니다.
  2. 키보드 배열, 설치 유형은 기본값.
  3. 네트워크 설정은 기본값(자동). 주소가 하나 잡히는지 눈으로 확인하세요.
  4. 프록시·미러는 비워 두거나 기본값.
  5. 저장소 설정: 디스크 전체 사용(기본값) → 확인 화면에서 Continue.
  6. 계정 만들기 — 이름, 서버 이름, 사용자명, 비밀번호. WSL2와 같은 사용자명을 쓰면 헷갈리지 않습니다.
  7. Install OpenSSH server 항목을 반드시 체크 (Space로 선택).
  8. 추가 패키지는 아무것도 선택하지 않고 설치 시작.
OpenSSH를 놓치면

Day 5의 원격 접속 실습을 할 수 없습니다. 지금 체크하는 편이 나중에 설치하는 것보다 훨씬 쉽습니다.

설치에 10~20분 걸립니다. 그동안 PART 3의 미션 1~2를 WSL2 창에서 미리 해 보세요.

STEP 5

첫 로그인

설치가 끝나면 Reboot Now. "설치 매체를 제거하라"는 메시지가 나오면 그냥 Enter를 누릅니다.

Password:

Welcome to Ubuntu ...
namo@ubuntu-server:~$
비교해 보기

WSL2 창과 이 VM 화면의 프롬프트를 나란히 놓고 보세요. 무엇이 같고 무엇이 다른가요?

STEP 6

스냅샷 — 되돌릴 지점 만들기

VirtualBox 창 메뉴에서 머신 → 스냅샷 찍기를 선택하고 이름을 clean-install로 합니다.

이제 이 VM은 마음껏 망가뜨려도 됩니다. 앞으로 권한을 잘못 건드리거나 서비스를 못 살리게 되면 이 지점으로 되돌리면 됩니다. 실습에서 과감해지세요.

PART 2 통과 조건
  • VM에 로그인되어 프롬프트가 보인다
  • uname -a가 출력된다
  • 스냅샷 목록에 clean-install이 있다

MISSION 05

지우기 — 가장 조심할 명령

리눅스에는 휴지통이 없습니다. rm으로 지운 것은 돌아오지 않습니다.

$ cd ~/practice
$ pwd                  ← 지우기 전에 반드시 위치 확인
/home/namo/practice

$ ls                   ← 무엇을 지우는지 눈으로 확인
a  memo.txt

$ rm memo.txt
$ rm a                 # 디렉터리는 이렇게는 안 지워집니다
rm: cannot remove 'a': Is a directory

$ rm -r a              # -r 을 붙여야 폴더째로
$ ls
# 비었습니다
평생 지킬 세 가지
  • rm -r 치기 전에 반드시 pwd와 ls
  • 경로 맨 앞의 / 하나 차이로 완전히 다른 곳을 지웁니다
  • 서버에서 sudo rm -rf는 지금 수준에서 절대 치지 않습니다
MISSION 06

모르는 걸 스스로 찾기 — 오늘의 핵심

앞으로 9일 동안 수십 개의 새 명령을 만납니다. 전부 외울 수는 없습니다. 찾는 법을 익히는 게 오늘 가장 중요한 미션입니다.

문제: ls로 파일 크기를 보면 4096 같은 숫자가 나옵니다. 이걸 4.0K처럼 사람이 읽기 쉽게 바꾸려면 어떤 옵션을 써야 할까요? 답을 검색하지 말고 아래 절차로 찾아내세요.

# 방법 1 — 도움말에서 걸러내기
$ ls --help | grep -i human
  -h, --human-readable  with -l and -s, print sizes like 1K 234M 2G etc.

# 방법 2 — 설명서에서 검색
$ man ls
#   /human   ← 슬래시 치고 검색어 입력 후 Enter
#   n        ← 다음 결과
#   q        ← 나가기

# 찾아낸 답을 적용
$ ls -alh /etc | head
total 856K
drwxr-xr-x 96 root root  4.0K Sep 14 09:10 .
-rw-r--r--  1 root root  3.0K Mar 31  2024 adduser.conf
...
이 절차를 외우세요

모르는 명령을 만나면 → 명령 --help → 그래도 모르면 man 명령 → 그래도 모르면 손 들기. 검색은 그다음입니다.

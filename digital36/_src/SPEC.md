# digital36 — 단원 파일 작성 규격

과정: **「디지털리터러시」 36시간** (정보통신IT · AX교과(실습) · 교수 김남호 · 401호)
지도목표: 생성형 인공지능을 활용하여 교육생이 디지털 사회에서 실생활 문제를 스스로 해결할 수 있는 역량을 기른다.
교재: 자체교재 (이 사이트)

## 수강생과 톤
- AI·디지털 기기가 **익숙하지 않은 성인 초보자**. 코딩 없음. 전문용어는 반드시 쉬운 말로 풀어 쓴다.
- 1차시 = **50분 수업 + 10분 휴식**. 설명 15~20분, 실습 30~35분 (실습 약 70%).
- PC실(인터넷 가능) + 개인 스마트폰 + 구글 계정. **무료 버전만으로** 모든 실습이 가능해야 한다.
- 존댓말(~입니다/~하세요). 강사가 실제로 말하듯 자연스럽게.

## 사실 정확성 (중요)
- 서비스 메뉴 이름·요금제는 자주 바뀐다. 확실하지 않은 메뉴 경로는 "화면 왼쪽 메뉴에서 ~를 찾으세요"처럼 **일반적으로** 쓰고, 필요하면 "메뉴 이름은 업데이트로 달라질 수 있습니다"를 붙인다.
- 유료 전용일 수 있는 기능(예: ChatGPT에서 GPTs *만들기*)은 실습 필수 경로로 쓰지 않는다. 맞춤 AI 만들기는 **Gemini 젬(Gems)** 을 기본으로 한다.
- 폐지되었거나 불확실한 서비스(예: SNU팩트체크, CLOVA X)는 쓰지 않는다.
- 쓸 수 있는 도구 예: ChatGPT, Google Gemini, Microsoft Copilot, Claude, Perplexity, NotebookLM, 네이버 파파고, 구글 번역, Google 렌즈, Canva, 클로바노트, 구글 드라이브/캘린더/Keep/Tasks, 정부24, 복지로, 118(KISA 불법스팸·해킹 상담), 112.
- 건강·금융·법률은 "AI 답은 참고용, 최종 판단은 전문가·공식기관" 원칙을 반드시 함께 가르친다.
- 개인정보(주민번호, 계좌, 비밀번호, 타인 사진 등)를 AI에 넣지 않도록 실습마다 주의 문구를 넣는다.

## 파일 형식 — `_src/unitN.js`

```js
module.exports = {
  unit: 1,                 // 단원 번호
  hours: 8,                // 이 단원 시수 (= blocks.length = lesson.length = lab.parts.length)
  title: '인공지능 시대의 디지털 리터러시',
  theme: '한 줄 부제',
  openingNar: `표지 나레이션`,

  goals: [ ['~를', '~할 수 있다'], ... ],   // 4~6개
  goalsNar: `...`,

  blocks: [ { time: '1차시', title: '차시 제목', desc: '핵심 키워드 · 키워드' }, ... ],  // 차시 수만큼
  blocksNar: `...`,

  slides: [ ... ],         // 아래 규칙
  assignment: { title, lede, subtitle, items: [...], note, sample, due, nar },
  wrap: { done, next, nextDesc, nar },

  lesson: [ ... ],         // 차시별 교안(교수학습지도안) — 아래 규칙
  lab: { h1, standfirst, rules: [[제목, 설명] x3], parts: [...], errors: [...], checklist: [...] },

  quizTitle: '...',
  quiz: [ ... ]            // 15문항
};
```

### slides[]
- 각 차시 시작에 구분 표지 1장: `{ section: true, eb: '1차시 · 50분', h: '차시 제목', sub: '한 줄', nar: `...` }`
- 차시마다 내용 슬라이드 **2~3장** → 단원 전체 약 22~30장.
- 내용 슬라이드: `{ eb: 'English Label', h: '제목', sub?: '', body: `HTML`, foot?: '', nar: `...` }`
- body에 쓸 수 있는 클래스 (이것만):
  - `<div class="grid g2|g3|g4">` + `<div class="card"><span class="n">라벨</span><span class="t">제목</span><span class="d">설명</span></div>` (`card warn` = 주의)
  - `<div class="rowlist">` + `<div class="row"><span class="dot">1</span><span class="t">제목</span><span class="d">설명</span></div>`
  - `<div class="stack">` + `<div class="lay"><b>제목</b><span>설명</span></div>`
  - `<div class="chips"><span class="chip">...</span><span class="chip bad">...</span></div>`
  - `<div class="banner">주의</div>`, `<div class="bannerG">강조</div>`
  - `<pre>` 프롬프트 예시: `<span class="p">나 ▶</span> 질문 내용` / `<span class="c"># 설명</span>`
  - 여백은 `style="margin-top:1.6cqh"` 식으로. 한 장에 글이 넘치지 않게 (카드 최대 6개, row 최대 5개, 설명은 한두 줄).
- **nar(나레이션)**: 브라우저 TTS가 읽는다. 영어·약어는 **한글 발음**으로 (ChatGPT → 챗지피티, AI → 에이아이, Gemini → 제미나이, URL → 유알엘, NotebookLM → 노트북엘엠, Perplexity → 퍼플렉시티, Canva → 캔바, QR → 큐알). 숫자는 읽기 자연스럽게. 한 장당 3~7문장.
- 첫 슬라이드들(표지·목표·차시 일정)과 과제·마무리 슬라이드는 빌더가 자동으로 만든다. slides[]에는 넣지 않는다.

### lesson[] — 차시별 교안 (운영계획서 표에 들어가는 내용)
차시마다 1개:
```js
{ no: 1, title: '차시 제목',
  objective: '이 차시 학습목표 한 문장 (~할 수 있다)',
  intro:  ['도입 활동 1', '도입 활동 2'],            // 5분 — 동기유발·전시확인
  main:   ['전개 활동 1', '전개 활동 2', '...'],     // 35분 — 설명 + 실습(실습 미션 번호 언급)
  close:  ['정리 활동 1', '정리 활동 2'],            // 10분 — 확인·예고
  method: '강의 · 시연 · 실습',                      // 교수방법
  material: 'PC, 스마트폰, 구글 계정',               // 준비물·매체
  eval: '관찰 체크리스트 — ~했는가' }                // 평가 방법
```

### lab — 학생용 실습지
- `parts[]`: **차시당 1개**. `{ pn: '1차시', h: '제목', time: '50분', lede: '안내 한 줄', missions: [ { n: 1, h: '미션 제목', body: `HTML` } ] }`
- 미션 번호 `n`은 단원 안에서 1부터 연속. 차시당 1~3개. 가장 중요한 미션 제목 끝에 ` ★`.
- body에 쓸 수 있는 요소: `<p>`, `<strong>`, `<ol>/<ul><li>`, `<kbd>`, `<code>`
  - 따라 하는 순서는 `<ol>`로 구체적으로 (어디를 누르고 무엇을 입력하는지)
  - 프롬프트 예시: `<pre><span class="p">나 ▶</span> ...\n<span class="o">AI ▶ 예상 답 요약</span>\n<span class="c"># 설명</span></pre>`
  - 작성칸(학생이 채우는 표): `<div class="dl"><div class="dlrow"><span class="k">라벨</span><span class="v">내용<small>보조 설명</small></span></div></div>`
  - `<div class="box check"><span class="lbl">확인</span><p>...</p></div>` / `box warn`(주의) / `box q`(생각해 보기)
- `errors[]`: `[증상, 원인, 대응]` 6~8개 (로그인 안 됨, 앱이 안 보임, AI가 엉뚱한 답 등 실제로 수업에서 나오는 문제)
- `checklist[]`: 8~10개, "~할 수 있다 / ~했다"
- `rules`: 실습 원칙 3개

### assignment
`{ title, lede, subtitle: '제출 방법 안내', items: [4~6개], note: '채점 기준', sample: '제출 양식 예시(텍스트, <span class="o">로 감싸기)', due: '다음 수업 시작 전', nar }`

### quiz[] — 15문항
- 객관식: `{ q, o: [정답, 오답, 오답, 오답], a: 0, e: '해설' }` (보기는 화면에서 섞이므로 정답을 0번에 두면 됨)
- 직접 입력(2~3개): `{ q: '... (직접 입력)', t: true, acc: ['허용답1','허용 답1'], ans: '대표답', e }` — 한 단어로 답할 수 있는 것만.
- 실생활 상황형 문제를 섞는다.

### wrap
`{ done: '오늘 한 일 한두 문장', next: '다음 · 2단원 — 제목', nextDesc: '예고 한두 문장', nar }` (마지막 단원은 next에 과정 수료 메시지)

### 1단원 (8시간)
1. 오리엔테이션, 디지털 리터러시란? — 사전 디지털 역량 자가진단
2. AI가 바꾼 일상(키오스크, 모바일 금융, 정부24, 추천 알고리즘) — 내 하루 속 AI 찾기
3. PC·스마트폰 기본기: 파일 관리, 클라우드(구글 드라이브) — 업로드·공유 링크 만들기
4. 검색 기본: 검색어 고르기, 검색 연산자, 믿을 만한 출처 — 검색으로 문제 해결
5. AI·머신러닝·생성형 AI·LLM 원리 쉽게 — "다음 단어 맞히기" 게임
6. 생성형 AI 서비스 둘러보기 + 사용 준비(ChatGPT, Gemini, Copilot, Claude, Perplexity 비교, 앱 설치·로그인) — 같은 질문 비교
7. 개인정보 보호와 보안: 비밀번호, 2단계 인증, 스미싱, AI 음성·영상 사기 — 계정 보안 점검
8. AI 윤리와 디지털 시민의식: 저작권, 딥페이크, 편향 — 사례 토론

### 2단원 (7시간)
1. ChatGPT 화면 구성, 무료와 유료, 모바일 앱과 음성 대화 — 첫 대화, 음성 질문
2. 좋은 질문의 4요소: 역할·상황·요청·형식 — 나쁜 질문 고치기
3. 대화 이어가기: 추가 질문, 수정 요청, 예시 보여주기 — 3번 이상 다듬기
4. AI가 틀릴 때(환각): 원인과 확인법 — 틀린 답 찾기, 교차 확인
5. 사진·파일로 질문하기: 설명서·안내문 사진, PDF 요약 — 스마트폰으로 찍어 묻기
6. 나만의 프롬프트 노트 — 자주 쓸 질문 템플릿 10개
7. 미니 프로젝트: 내 생활 질문 해결 — 기록과 발표

### 3단원 (7시간)
1. 글쓰기 도우미: 이메일, 문자, 안내문, 자기소개서 초안 — 문서 3종
2. 번역과 외국어: 번역 앱, AI 음성 회화 연습 — 여행·민원 역할극
3. 생활정보: 냉장고 사진 레시피, 여행 일정, 건강정보 주의점 — 1박 2일 여행 계획
4. 가계·소비: 지출 정리, 요금제·상품 비교표 (AI 조언의 한계) — 지출 분류표
5. 공공서비스: 정부24·복지로 정보 찾기, 어려운 공문서 쉽게 풀기 — 지원제도 찾기
6. 이미지 만들기: 초대장·포스터·카드뉴스 (AI 이미지 생성, Canva) — 포스터 제작
7. 실습: 나의 생활 문제 1개 해결 — 문제→질문→결과→확인 기록

### 4단원 (7시간)
1. 정보 과잉과 허위정보: 가짜뉴스 유형 — 진짜/가짜 구별 퀴즈
2. AI 검색 도구(Perplexity, Gemini, ChatGPT 검색)와 출처 확인 — 출처 링크 직접 열기
3. 사실 확인 3단계: 출처 → 날짜 → 다른 자료로 교차 확인 — 화제 이슈 1건 확인
4. AI 생성 이미지·영상·음성(딥페이크) 알아보기 — 판별 실습, Google 렌즈 이미지 검색
5. 여러 자료 요약·정리(NotebookLM) — 자료 3개로 요약본·마인드맵
6. 표와 그래프 읽기, AI로 스프레드시트 기초(구글 시트) — 공공데이터 표 해석·그래프
7. 1페이지 정보 리포트 작성 — 출처와 AI 사용 여부 표기

### 5단원 (7시간)
1. 디지털 웰빙: 사용 시간 진단, 알림 정리 — 스크린타임(디지털 웰빙) 분석
2. 일정·할 일 관리: 구글 캘린더, 할 일 앱, AI 주간 계획 — 캘린더 등록
3. 기록 습관: 클라우드 메모, 음성 녹음 → AI 요약(클로바노트 등) — 녹음 요약본
4. 나만의 AI 비서 만들기(Gemini 젬 / ChatGPT 맞춤 설정) — 목적별 맞춤 AI 1개
5. 루틴 설계: 아침·업무·학습 루틴과 도구 연결 — 루틴 흐름도
6. 최종 프로젝트: 나만의 디지털 루틴북 (1~5단원 결과물 포트폴리오) — 제작
7. 발표와 마무리 — 발표, 사후 역량 진단, 과정 평가

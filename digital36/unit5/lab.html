5단원 · 나만의 디지털 루틴 만들기

이번 단원은 지금까지 배운 것을 "매일 쓰는 습관"으로 바꾸는 시간입니다. 내 휴대폰 사용을 진단하고, 캘린더·메모·녹음 요약·나만의 AI 비서를 설정한 뒤, 이 도구들을 하나의 루틴으로 이어 붙입니다. 마지막에는 1~5단원 결과물을 모은 디지털 루틴북을 완성해 발표합니다. 모든 실습은 무료 버전으로 할 수 있습니다.

RULE 1

내 생활에 맞게

예시를 그대로 따라 하지 말고, 내 실제 일정·습관에 맞게 바꾸세요. 내 것이어야 과정이 끝난 뒤에도 씁니다.

RULE 2

개인정보는 빼고

주민등록번호·계좌·비밀번호·주소·전화번호는 AI 질문, 메모, 캡처 어디에도 넣지 마세요. 캡처는 가리고 저장합니다.

RULE 3

작게, 확인하며

AI가 만든 계획·요약은 초안입니다. 이름·숫자·날짜를 직접 확인하고, 루틴은 5분짜리 하나부터 시작합니다.

시작 전 — 녹음 동의

짝에게 "실습용으로 2분만 녹음해도 될까요?"라고 먼저 묻고, 동의를 받은 뒤 시작합니다. 내가 참여하지 않은 다른 사람들끼리의 대화를 몰래 녹음하면 통신비밀보호법 위반이 될 수 있습니다. 동의를 원하지 않는 분은 혼자 안내문을 소리 내어 읽어 녹음합니다.

방법 A — 클로바노트 (네이버 계정 필요)

  1. 스마트폰에 클로바노트 앱을 설치하고 네이버 계정으로 로그인합니다.
  2. 녹음 버튼을 눌러 짝과 2분 동안 대화합니다. 주제 예) 이번 주말 계획과 필요한 준비물
  3. 녹음을 멈추고 저장하면 글로 변환될 때까지 잠시 기다립니다.
  4. 노트 화면에서 AI 요약(또는 요약 메뉴)을 확인합니다.
  5. 변환된 글과 요약에서 사람 이름·숫자·날짜·장소가 맞는지 녹음을 다시 들으며 고칩니다.
  6. 완성한 요약을 복사해 구글 Keep의 배움 라벨 메모에 붙여 넣습니다.

과제 05

나만의 디지털 루틴북 완성·제출

제출: 7차시 발표 시작 전 (실천 체크표는 수료 후에도 계속 채워 나가기)

1~5단원 결과물을 목차대로 묶고, 실제로 루틴을 실천한 기록과 사후 진단·소감까지 담아 제출합니다.

제출 항목

구글 드라이브 공유 링크(뷰어 권한)를 과정 게시판 또는 강사가 안내한 곳에 제출

  1. 루틴북 파일 1개 (구글 문서·슬라이드·캔바 중 선택) — 목차 0~5장 모두 포함
  2. 5장: 디지털 웰빙 진단 전·후 숫자 + 알림 정리 내용
  3. 5장: 나의 젬(또는 ChatGPT 맞춤 설정) 지침 전문과 시험 대화 캡처 1장
  4. 5장: 루틴 흐름도 1개 + 3일 이상 실천 체크표
  5. 마지막 쪽: 사전·사후 역량 자가진단 10문항 점수 비교표
  6. 마지막 쪽: 세 문장 소감 (기억에 남는 것 · 달라진 것 · 계속할 것)
제출 양식 예시
이름 : 홍길동 / 제출일 : ○월 ○일
링크 : (구글 드라이브 공유 링크 · 뷰어 권한)

5장. 나의 디지털 루틴
  웰빙 진단 : 하루 사용 5시간 10분 → 4시간 20분 / 알림 하루 180개 → 70개
  나의 젬   : "공부 코치" — 지침 전문 첨부, 시험 대화 캡처 1장
  루틴      : 화·목 20:00 반복 알림 → 공부 코치 젬 퀴즈 5문제 → Keep "배움" 라벨 저장
  실천 체크 : 화 ✔ / 목 ✔ / 토(보충) ✔

마지막 쪽. 자가진단 비교 (사전 → 사후)
  5번 좋은 질문 다듬기 : 1 → 4  ← 가장 많이 오름
  8번 가짜뉴스 확인   : 2 → 3  ← 계속 연습할 목표
소감 : 에이아이가 어렵기만 했는데 이제 매일 씁니다. 캘린더 알림 덕분에 약속을 잊지 않습니다. 수료 후에도 공부 코치 젬과 주 2회 복습을 계속하겠습니다.

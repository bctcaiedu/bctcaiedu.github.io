과제 02

프롬프트 노트 완성과 생활 질문 해결 기록

제출: 다음 수업 시작 전

이번 단원의 결과물 두 가지 — 다시 쓸 질문 템플릿 10개와, 내 생활 문제 하나를 해결한 기록을 제출합니다.

제출 항목

구글 문서 1개에 모아 작성하고, 공유 링크(보기 권한)를 강사에게 제출합니다

  1. 프롬프트 노트: 템플릿 10개 (빈칸 [ ] 포함) + 그중 3개는 실제로 채워 쓴 예
  2. 나쁜 질문 → 좋은 질문 고치기 1쌍 (4요소 표시)
  3. 대화 다듬기 기록: 첫 질문과 추가·수정 요청 3번 이상
  4. 환각 확인 기록 1건: AI 답 / 확인에 쓴 자료 / 판정(맞음·틀림·확인 불가)
  5. 미니 프로젝트 기록 양식 (문제·질문 변화·결과·확인·배운 점)
  6. 개인정보(이름·연락처·주민번호·계좌)가 들어가지 않았는지 최종 점검
제출 양식 예시
이름 : 홍길동

[미니 프로젝트] 부모님 칠순 식사 장소 고르기
1. 문제   : 부모님 모시고 12명이 식사할 조용한 한식당 찾기
2. 첫 질문 : "칠순 식당 추천해 줘"
3. 다듬기  : ① 12명, 룸 있는 곳, ○○구 근처로 조건 추가
            ② 1인 예산 3만 원 이내로 수정
            ③ 식당 고를 때 전화로 물어볼 질문 5개 요청
4. 결과   : 식당 후보 3곳 + 예약 전화 체크리스트
5. 확인   : 후보 중 1곳은 지도 앱에서 폐업으로 확인 → 제외
            나머지 2곳 룸·영업시간은 식당에 직접 전화로 확인
6. 배운 점 : 식당·가게 정보는 AI 답을 그대로 믿지 말고 지도 앱과 전화로 확인한다
채점 기준

결과가 멋진지보다 과정이 보이는지를 봅니다. ① 4요소를 넣었는가 ② 3번 이상 다듬었는가 ③ 중요한 사실을 AI가 아닌 자료로 확인했는가 ④ 개인정보를 뺐는가 — 네 가지로 평가합니다.

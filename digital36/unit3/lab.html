이번 단원은 "배운 것을 오늘 집에서 바로 쓰는 것"이 목표입니다. 문자 한 통, 여행 일정표 한 장, 지출 분류표, 포스터 한 장처럼 눈에 보이는 결과물을 차시마다 하나씩 만듭니다. 그리고 건강·돈·공공서비스에 관한 AI 답은 반드시 공식기관과 원문으로 확인합니다.

RULE 1

개인정보는 빈칸으로

이름·전화번호·주소·주민번호·계좌번호·진료기록 원문은 AI에 넣지 않습니다. [이름]처럼 비워 두고 보내기 전에 직접 채우세요.

RULE 2

초안은 AI, 결정은 나

AI가 준 글·표·일정은 초안입니다. 날짜·금액·장소는 내가 직접 확인하고, 건강·금융 판단은 전문가와 공식기관에 맡깁니다.

RULE 3

한 번 더 다듬는다

첫 답에서 멈추지 마세요. "더 짧게", "표로", "없는 내용은 없다고" 같은 요청을 두 번 이상 해 보세요.

과제 03

나의 생활 문제 해결 기록서

제출: 다음 수업 시작 전

이번 단원에서 배운 AI 활용법으로 실제 생활 문제 하나를 해결하고, 과정을 기록으로 남깁니다.

제출 항목

한글·워드 문서 또는 구글 문서 1장에 작성하여 구글 드라이브 공유 링크로 제출

  1. 해결한 생활 문제를 한 문장으로 적기
  2. AI에게 한 첫 질문과 다듬은 질문(2번 이상) 원문 그대로 붙이기
  3. AI 결과 화면 캡처 1장 이상
  4. 결과를 확인한 방법 적기 (공식 사이트 · 전문가 · 원문 대조 · 계산기 등)
  5. 이번 단원 결과물 1개 첨부 (문서 3종 · 여행 일정표 · 지출 분류표 · 포스터 중 택1)
  6. 개인정보를 가렸는지 스스로 점검한 결과 (예/아니오와 가린 항목)
제출 양식 예시
이름 : 홍길동

1. 문제 : 어머니와 강릉 1박 2일 여행 일정을 짜야 한다.
2. 첫 질문 : 강릉 1박 2일 여행 일정 짜 줘.
   다듬은 질문 : 70대 어머니와 기차로 가. 많이 걷지 않는 코스로,
               시간대별 표로, 이동 시간도 적어 줘.
3. 결과 : 일정표 캡처 첨부
4. 확인 : 기차 시간은 예매 앱으로, 카페 휴무일은 지도 앱으로 확인
          → 둘째 날 방문지 1곳 휴무라 다른 곳으로 변경
5. 결과물 : 여행 일정표 첨부
6. 개인정보 : 예 (어머니 이름·연락처 넣지 않음)
채점 기준

채점 기준: ① 질문에 상황·요청·형식이 들어가고 다듬기를 했는가(30%) ② 결과를 실제로 확인했고 확인 방법이 구체적인가(40%) ③ 개인정보를 가렸는가(20%) ④ 결과물이 첨부되었는가(10%). 확인 칸이 비어 있으면 감점이 큽니다.

# digital36 — 「디지털리터러시」 36시간 과정

`bctcaiedu.github.io`의 **physicalai48**과 같은 구조로 만든 정적 강의 사이트입니다.
단원마다 **강의 슬라이드(나레이션) · 차시별 교안 · 실습지 · 퀴즈** 4종이 만들어지고,
과정 전체의 **교과 운영계획서**(운영계획서 표 양식)가 함께 만들어집니다.

| 항목 | 내용 |
|---|---|
| 교과목명 | 디지털리터러시 |
| 대상직종 · 교과 구분 | 정보통신IT · AX교과(실습) |
| 교육훈련시간 | 36시간 (1차시 = 50분 수업 + 10분 휴식) |
| 교수명 · 훈련시설 | 김남호 · 401호 |
| 지도목표 | 생성형 인공지능을 활용하여 교육생이 디지털 사회에서 실생활 문제를 스스로 해결할 수 있는 역량을 기른다. |

```
digital36/
├── index.html          ← 과정 표지 (자동 생성)
├── plan.html           ← 교과 운영계획서 · 36차시 세부 교수계획 · 평가 계획 (자동 생성, 인쇄 가능)
├── nav.js              ← 공통 목차 사이드바 (자동 생성)
├── unit1 ~ unit5/
│   ├── index.html      ← 강의 슬라이드 (TTS 나레이션 · 자막 · 자동진행)
│   ├── lesson.html     ← 차시별 교안 (학습목표 · 도입/전개/정리 · 교수방법 · 준비물 · 평가) — 인쇄 가능
│   ├── lab.html        ← 학생용 실습지 (차시별 미션 · 문제 해결표 · 체크리스트 · 과제)
│   └── quiz.html       ← 퀴즈 15문항 (즉시 채점 + 해설)
└── _src/               ← 원본. 여기만 고치고 다시 빌드합니다
    ├── build.js        ← 과정 정보(COURSE_INFO)·평가 배점도 여기
    ├── SPEC.md         ← 단원 파일 작성 규격
    ├── unit1.js ~ unit5.js
    ├── css/  deck.css · lab.css · quiz.css
    └── js/   deck.js · quiz.js · nav.tpl.js
```

## 파이썬 확장 실습 (선택)

앞 교과 「파이썬 기초」(자료형·조건문·반복문·자료구조·함수·파일 입출력, pandas 없음)를 이어받아
**AI에게 코드를 받고 → 실행하고 → 검증**하는 선택 미션 8개입니다. 실습지에는 파란색 **PYTHON 미션**으로, 교안에는 **확장(선택)** 줄로 들어갑니다.

| 미션 | 단원·차시 | 내용 | 노트북 |
|---|---|---|---|
| P1 | 1-5 | 딕셔너리로 "다음 단어 맞히기" 모델 | `python/unit1_python.ipynb` |
| P2 | 1-7 | `secrets` 비밀번호 생성기 · 강도 검사기 | 〃 |
| P3 | 2-4 | AI가 짠 코드의 실행·논리·경계값 오류 찾기 | `python/unit2_python.ipynb` |
| P4 | 2-6 | 코드 요청 템플릿 → 테스트로 검증 | 〃 |
| P5 | 3-4 | 지출 CSV 분류·합계 · 요금제 기간별 비교 | `python/unit3_python.ipynb` |
| P6 | 4-6 | 도서관 데이터 교차 검증 · 상관≠인과 | `python/unit4_python.ipynb` |
| P7 | 5-2 | 루틴 → `.ics` 캘린더 파일 → 구글 캘린더 가져오기 | `python/unit5_python.ipynb` |
| P8 | 5-6 | 습관 기록 달성률·연속일·주간 비교 → 루틴북 보고서 | 〃 |

- 원본: `_src/python/unitN.js` (실습지 미션 + 노트북 셀). `code`는 학생용, `answer`는 답안용 셀입니다.
- 빌드하면 `python/*.ipynb`(학생용)와 `python/answers/*_answers.ipynb`(교수자용 답안)가 함께 만들어집니다.
  **답안을 학생에게 공개하지 않으려면 `python/answers/` 폴더는 저장소에 올리지 마세요.**
- "Colab에서 열기" 링크는 `_src/build.js`의 `GITHUB`(저장소 `bctcaiedu/bctcaiedu.github.io`, 브랜치 `main`) 기준입니다. 브랜치 이름이 다르면 고치고 다시 빌드하세요.
- 그래프 셀은 선택입니다. Colab에서 한글 글꼴(나눔고딕)을 자동 설치합니다. 기본 결과는 글자 막대(■)라 글꼴 없이도 보입니다.

## 빌드

Node.js만 있으면 됩니다. 별도 패키지 설치 없음.

```bash
node _src/build.js
```

```bash
node _src/build.js 3
```

(두 번째는 3단원만 다시 빌드. 표지·운영계획서·목차는 항상 전체 기준으로 다시 만듭니다.)

## 내용 수정

HTML을 직접 고치지 마세요. **`_src/unitN.js`만 고치고 다시 빌드**합니다.

| 고치고 싶은 것 | 파일 · 위치 |
|---|---|
| 교과명 · 교수명 · 훈련시설 · 평가 배점 | `_src/build.js` → `COURSE_INFO` |
| 기관명 | `_src/build.js` → `ORG` |
| 슬라이드 · 나레이션 | `_src/unitN.js` → `slides[]` |
| 차시별 교안(도입·전개·정리) | `_src/unitN.js` → `lesson[]` |
| 실습 미션 | `_src/unitN.js` → `lab.parts[].missions[]` |
| 문제 해결표 · 체크리스트 | `_src/unitN.js` → `lab.errors[]`, `lab.checklist[]` |
| 과제 | `_src/unitN.js` → `assignment` |
| 퀴즈 | `_src/unitN.js` → `quiz[]` |

차시 수를 바꾸면 `hours`, `blocks[]`, `lesson[]`, `lab.parts[]` 개수를 함께 맞추세요. 안 맞으면 빌드할 때 경고가 나옵니다.
필드 형식과 슬라이드에 쓸 수 있는 클래스는 `_src/SPEC.md`에 정리되어 있습니다.

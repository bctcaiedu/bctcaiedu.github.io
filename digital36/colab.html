1장

구글 코랩이란?

개념

한 문장으로: "구글의 컴퓨터를 잠시 빌려, 인터넷 창에서 파이썬을 실행하는 무료 노트"입니다.

1-1

코랩은 "코딩용 구글 문서"

구글 문서(Docs)에 글을 쓰면 내 PC가 아니라 구글 드라이브에 저장되듯, 코랩에 쓴 코드도 구글 드라이브에 저장됩니다. 코드를 실행하는 컴퓨터도 내 PC가 아니라 구글 데이터센터의 가상 컴퓨터입니다. 그래서 파이썬을 설치하지 않아도 되고, 느린 PC에서도 똑같이 돌아갑니다.

코랩의 문서 한 개를 노트북(Notebook)이라고 부릅니다. 노트북은 셀이라는 칸으로 나뉘고, 칸마다 코드나 설명 글을 적습니다. 파일 이름 끝은 .ipynb(아이파이앤비)이며, 전 세계에서 많이 쓰는 주피터(Jupyter) 노트북과 같은 형식입니다.

💻 설치가 필요 없다Chrome 같은 인터넷 창과 구글 계정만 있으면 됩니다. 파이썬·경로 설정 없음.
🆓 기본은 무료무료로도 수업·과제에는 충분합니다. 무거운 인공지능 학습용 GPU도 쓸 수 있습니다(보장은 아님).
☁️ 드라이브 저장 · 링크 공유자동으로 드라이브에 저장되고, 구글 문서처럼 링크로 공유·제출합니다.
✨ AI 도우미코랩 안의 Gemini가 코드 작성·오류 설명을 돕습니다. (기능·이름은 자주 바뀝니다)
무료 사용의 한계 — 꼭 알아 두기
  • 오래 가만히 두면 연결이 끊깁니다. 한 번에 쓸 수 있는 시간에도 상한이 있습니다. 정확한 시간은 구글 정책·사용량에 따라 달라집니다.
  • 연결이 끊기거나 세션을 다시 시작하면 변수와 업로드한 파일이 지워집니다. 코드와 글(노트북 자체)은 드라이브에 남습니다.
  • GPU 같은 고성능 장치는 사람이 몰리면 못 쓸 수 있습니다. 이 과정 실습에는 필요 없습니다.
  • 더 오래·더 빠르게 쓰려면 유료 요금제가 있지만, 이 과정은 무료 버전만으로 충분합니다.
이럴 때 코랩을 씁니다

AI가 준 파이썬 코드를 바로 실행해 볼 때 · 엑셀처럼 표를 계산하고 그래프를 그릴 때 · 공유 링크로 과제를 낼 때 · 설치가 막힌 공용 PC에서 파이썬을 써야 할 때

2-1

접속하고 새 노트북 만들기

  1. 주소창에 colab.research.google.com 을 입력합니다. (검색창에 "구글 코랩"을 검색해도 됩니다)
  2. 오른쪽 위 로그인을 눌러 구글 계정으로 로그인합니다. 이미 로그인되어 있다면 오른쪽 위 프로필 사진으로 내 계정이 맞는지 확인합니다.
  3. 처음 뜨는 창에서 + 새 노트북을 누릅니다. 창이 안 뜨면 메뉴 파일 → 새 노트북(버전에 따라 "Drive의 새 노트북").

4장

셀 다루기

핵심

노트북은 셀을 쌓아 만듭니다. 셀은 딱 두 종류, 코드 셀과 텍스트 셀입니다.

4-1

코드 셀 — 실행하는 칸

파이썬 코드를 쓰고 실행하면 바로 아래에 결과가 나옵니다. 셀의 마지막 줄에 있는 값은 print() 없이도 보입니다.

# 코드 셀에 입력
In ▶ 12000 * 3 + 4500
Out  40500
4-2

실행하는 방법 3가지

방법동작언제
셀 왼쪽 ▶ 클릭그 셀만 실행처음 배울 때
Shift + Enter실행하고 다음 셀로 이동위에서부터 차례로 실행할 때 (가장 많이 씀)
Ctrl + Enter실행하고 그 자리에 머묾숫자를 바꿔 가며 여러 번 실행할 때

셀이 실행 중이면 ▶ 자리가 돌아가는 모양으로 바뀝니다. 멈추고 싶으면 그 버튼(■)을 다시 누르거나 런타임 → 실행 중단.

4-3

실행 번호 [1] [2] [3] — "순서가 중요하다"

셀 왼쪽의 숫자는 실행한 순서입니다. 화면의 위아래 순서가 아닙니다. 코랩은 셀을 실행할 때마다 그 결과(변수)를 기억하고, 다른 셀에서 그 기억을 함께 씁니다.

[1] 이름 = "홍길동"          # 첫 번째 셀: 변수 만들기
[2] print(이름, "님 반가워요")  # 두 번째 셀: 위 변수 쓰기
    홍길동 님 반가워요
자주 하는 실수

두 번째 셀만 실행하면 NameError: name '이름' is not defined — "이름이라는 걸 모른다"는 오류가 납니다. 위 셀을 먼저 실행하세요. 헷갈리면 런타임 → 모두 실행 또는 이전 셀 실행.

4-4

올리기 · 내려받기 · 연결

파이썬으로 엑셀·CSV·텍스트 파일을 읽으려면 파일이 런타임(가상 컴퓨터) 안에 있어야 합니다.

6-1

파일 올리기 (업로드)

  1. 왼쪽 📁 파일 아이콘을 누릅니다.
  2. PC의 파일을 이 창으로 끌어다 놓거나, 위쪽 업로드 아이콘을 누릅니다.
  3. 코드에서는 파일 이름만 쓰면 됩니다: open("장보기.txt")

6-2

파일 내려받기 (다운로드)

📁 파일 창에서 파일 이름 옆 ⋮ → 다운로드. 또는 코드로:

from google.colab import files
files.download("장보기.txt")
6-3

구글 드라이브 연결 — 파일을 오래 두고 싶을 때

업로드한 파일은 세션이 끝나면 지워집니다. 드라이브를 연결하면 내 드라이브의 파일을 바로 읽고, 결과를 드라이브에 저장할 수 있습니다.

from google.colab import drive
drive.mount("/content/drive")
Mounted at /content/drive

7-1

입력 폼 — 코드를 몰라도 값을 바꾸는 칸

코드 줄 끝에 # @param을 붙이면 셀 오른쪽에 입력 칸 · 슬라이더 · 체크박스 · 선택 목록이 생깁니다. 계산기를 만들어 다른 사람에게 줄 때 좋습니다.

# @title 🍚 한 달 점심값 계산기 { run: "auto" }
점심값 = 9000   # @param {type:"slider", min:5000, max:15000, step:500}
주당_횟수 = 5   # @param {type:"integer"}
요일 = "월"     # @param ["월", "화", "수", "목", "금"]
커피 = True     # @param {type:"boolean"}

{ run: "auto" }를 붙이면 값을 바꿀 때마다 자동으로 다시 실행됩니다. 셀의 ⋮ → 양식 → 코드 숨기기로 코드를 가리고 입력 칸만 보이게 할 수도 있습니다(메뉴 이름은 달라질 수 있음).

7-2

! 명령어와 패키지 설치

줄 앞에 !를 붙이면 파이썬이 아니라 가상 컴퓨터(리눅스)의 명령어가 됩니다. pandas, numpy, matplotlib 같은 유명한 패키지는 이미 설치되어 있고, 없는 것만 설치하면 됩니다.

!ls                    # 지금 폴더의 파일 목록
!pip install -q qrcode # qrcode 패키지 설치 (-q: 조용히)
# ⚠️ 세션이 새로 시작되면 설치도 지워집니다 → 설치 셀을 맨 위에 두고 다시 실행
7-3

코랩 안의 AI 도우미 (Gemini)

코랩에는 구글의 AI인 Gemini가 들어 있습니다. 무료 계정에서도 쓸 수 있지만, 버튼 이름·위치·사용량은 자주 바뀝니다. 대표적인 쓰임은 세 가지입니다.

  • 코드 만들기 — 빈 코드 셀의 "생성"(AI로 생성) 안내를 누르고 "1부터 100까지 짝수의 합을 구해 줘"처럼 한국어로 요청
  • 오류 설명 — 오류가 난 셀 아래의 "오류 설명" 버튼 → 원인과 고친 코드를 제안
  • 채팅 — 화면의 Gemini 아이콘으로 대화창을 열어 노트북 내용에 대해 질문
AI 코드 사용 원칙 (2단원 복습)

AI가 준 코드는 ① 실행해 보고 ② 답을 아는 예시로 테스트하고 ③ 모르는 줄은 설명을 요청한 뒤 씁니다. 버튼이 안 보이면 ChatGPT·Gemini 웹에 물어보고 코드를 복사해 와도 똑같습니다.

Mac은 Ctrl 대신 ⌘ Cmd. Ctrl+M B는 "Ctrl+M을 누르고 손을 뗀 뒤 B"입니다. 단축키는 도구 → 단축키에서 바꿀 수 있습니다.

안전 수칙 5가지
  • 코드·텍스트 셀에 비밀번호 · 주민번호 · 계좌번호 · 카드번호를 쓰지 않습니다.
  • AI 서비스의 API 키는 코드에 직접 쓰지 않고 🔑 보안 비밀에 보관합니다. 공유 노트북에 키가 보이면 즉시 키를 폐기합니다.
  • 출처를 모르는 노트북은 실행하지 않고, 드라이브 연결 권한을 주지 않습니다.
  • 공유 전 수정 → 모든 출력 지우기로 결과 화면의 개인정보를 확인합니다.
  • 공용 PC에서는 수업이 끝나면 구글 로그아웃합니다.

자가 점검 체크리스트

  • 코랩이 "구글의 컴퓨터를 빌려 쓰는 노트"라는 것을 설명할 수 있다.
  • 새 노트북을 만들고 이름을 바꿔 드라이브의 Colab Notebooks 폴더에서 찾을 수 있다.
  • 코드 셀을 Shift+Enter로 실행하고 실행 번호의 뜻을 안다.
  • NameError가 나면 "이전 셀 실행" 또는 "모두 실행"으로 스스로 복구할 수 있다.
  • 텍스트 셀에 제목·굵게·목록을 써서 설명을 남길 수 있다.
  • 입력 폼(# @param)으로 값을 바꿔 계산기를 쓸 수 있다.
  • 파일을 올리고 내려받을 수 있고, 세션이 끝나면 지워진다는 것을 안다.
  • !pip install로 패키지를 설치해 QR 코드를 만들었다.
  • 오류의 마지막 줄을 읽고 NameError · TypeError · SyntaxError를 고쳤다.
  • AI에게 받은 코드를 테스트로 검증하고, 뷰어 권한 공유 링크로 제출했다.

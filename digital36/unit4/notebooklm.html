NotebookLM · 일기장으로 연습하기

내가 올린 PDF만 읽고 답하는 구글의 AI 노트, NotebookLM(지금 이름 Gemini Notebook)을 연습합니다. 앞부분은 왕초보 사용법, 뒷부분은 연습용 일기장으로 푸는 미션 15개입니다. 일기장은 사람·날짜·돈·기분이 계속 나와서, AI의 답이 맞았는지 내가 직접 확인하기 쉽습니다.

4단원 실습지차시별 교안강의 슬라이드과정 표지
RULE 1

근거 번호를 꼭 누른다

답 문장 끝의 작은 숫자를 누르면 원본이 열립니다. 숫자·날짜·금액이 나오면 반드시 확인합니다.

RULE 2

"없다"는 정답일 수 있다

"답할 수 없습니다"는 고장이 아니라 파일에 그 내용이 없다는 뜻입니다. 지어내지 않은 것이에요.

RULE 3

비밀 문서는 올리지 않는다

올린 파일은 구글 서버로 전송됩니다. 주민번호·계좌·회사 문서는 넣지 않고, 연습은 공개 자료로 합니다.

1장

NotebookLM이란?

개념

한 문장으로: "내가 준 책을 다 읽은 친구가 옆에 앉아, 몇 쪽에 나오는지 짚어 주며 대답하는 것"입니다.

1-1

다른 AI와 무엇이 다를까

ChatGPT 같은 AI는 인터넷에서 배운 지식으로 답하기 때문에, 모르는 것도 그럴듯하게 지어낼 때가 있습니다(환각). NotebookLM은 내가 올린 파일 안의 내용만 가지고 답하고, 파일에 없으면 "없다"고 하거나 답하지 않습니다. 그리고 답할 때마다 어느 자료 어디에서 가져왔는지 근거 번호를 붙입니다.

📄 어려운 논문"이거 한 문장으로 설명해 줘" 시키기
📝 수업 자료퀴즈와 암기 카드를 만들어 달라고 하기
🎧 보고서두 사람이 대화하는 팟캐스트 같은 오디오로 듣기
이름과 주소가 바뀌었어요
  • 2026년 7월 16일부터 이름이 Gemini Notebook(제미나이 노트북)으로 바뀌었습니다. 바뀐 건 이름과 로고뿐이고, 쓰던 노트북·파일·오디오는 그대로입니다.
  • 지금 주소는 notebook.google.com입니다. 예전 주소 notebooklm.google.com으로 들어가도 자동으로 넘어갑니다.
  • 인터넷 설명 글과 이 자료에서는 편하게 "NotebookLM"이라고 부릅니다. 같은 서비스입니다.
2장

시작하기 · 화면 세 칸

10분

준비물은 구글 계정 하나와 PDF 파일 하나입니다. 돈이나 카드 등록은 필요 없습니다. 처음 배울 때는 PC(크롬)를 권장합니다.

2-1

들어가서 PDF 올리기

  1. 주소창에 notebook.google.com을 입력하고 구글 계정으로 로그인합니다. (구글에서 "NotebookLM"으로 검색해도 됩니다)
  2. 새 노트북 만들기(영어 화면: Create new notebook)를 누릅니다.
  3. "파일을 올리세요" 창에 PDF를 끌어다 놓거나 눌러서 고릅니다.
  4. 동그라미가 돌다가 멈추고 왼쪽 소스 칸에 파일 이름이 뜨면 성공! 보통 10초~1분, 쪽수가 많으면 몇 분 걸립니다.
  5. 가운데 칸에 시키지 않은 요약과 "이런 걸 물어보면 어때요?" 질문 예시가 이미 떠 있습니다. 먼저 읽어 보세요.
왼쪽 · SOURCE소스올린 PDF가 모이는 책장. 여러 개를 올렸으면 볼 파일만 체크합니다.
가운데 · CHAT채팅질문하고 답을 받는 곳. 답에 붙은 근거 번호를 누릅니다. 가장 많이 씁니다.
오른쪽 · STUDIO스튜디오메모 저장, 오디오·영상 요약, 마인드맵, 퀴즈, 암기 카드를 만드는 공장.

3장

근거 번호와 질문 잘하는 법

핵심

이 장 하나만 몸에 배어도 NotebookLM을 잘 쓰는 사람입니다.

3-1

제일 중요한 기능 — 근거 번호

답 문장 끝에 붙은 1, 2 같은 작은 숫자를 누르면, 왼쪽에 원본 PDF가 열리며 그 답을 어디서 가져왔는지 보여 줍니다. AI 말은 가끔 틀리기 때문에, 진짜 그렇게 쓰여 있는지 내 눈으로 확인하는 습관이 가장 중요합니다.

"Gemini Notebook은 이 질문에 답할 수 없습니다"가 나오면 고장이 아닙니다. 파일에 그 내용이 없다는 뜻이니, 낱말을 바꿔 다시 묻거나(예: "휴가" → "연차") 정말 없는 내용인지 생각해 봅니다.

3-2

파일을 여러 개 올렸을 때

파일 이름을 말하면 정확해집니다. "'사용설명서.pdf'에서 고장 났을 때 부분만 알려 줘". 또는 왼쪽 소스 칸에서 볼 파일만 체크합니다. 노트북끼리는 서로의 파일을 못 보니, 함께 볼 파일은 한 노트북에 넣습니다.

3-3

답변 스타일 바꾸기 — 채팅 설정

채팅 칸의 채팅 설정(영어: Configure Chat)에서 말하는 방식과 길이(짧게/보통/길게)를 고르고 저장합니다.

고르는 것이럴 때 좋아요
기본 (Default)이것저것 물어볼 때. 처음엔 이거면 됩니다.
학습 가이드 (Learning Guide)공부할 때. 선생님처럼 차근차근 가르쳐 줍니다.
맞춤 (Custom)직접 정하기. "초등학생도 이해할 수 있게, 짧은 문장으로 설명해 줘"라고 써 두면 계속 그렇게 답합니다.
3-4

마음에 드는 답 저장하기

답변 아래 노트에 저장(Save to note)을 누르면 오른쪽 스튜디오에 메모로 붙습니다. 메모 옆 ⋮에서 구글 문서·시트로 내보낼 수 있어 7차시 리포트에 바로 씁니다.

5장

왜 일기장으로 연습할까?

준비 5분

설명서나 논문으로 연습하면 내가 내용을 모르니 답이 맞았는지 확인하기 어렵습니다. 일기장은 사람 이름 · 날짜 · 돈 · 기분이 계속 나오고, 넉 달 동안 여러 이야기가 동시에 흘러가서 물어볼 것도 많고 확인하기도 쉽습니다.

이야기어떻게 흘러가요
회사일정 빡빡한 팀장님 → 퇴사 → 새 팀장님이 오면서 분위기가 바뀝니다
자격증 공부접수 → 미루기 → 벼락치기 → 시험 → 결과
이사갑자기 나가라는 통보 → 집 보러 다니기 → 계약 → 이사
러닝3km도 힘들었는데 조금씩 늘어납니다
식물 키우기몬스테라를 사는데, 중간에 죽을 뻔해요
사람들친구 지우, 소개팅으로 만난 태오. 둘 다 이야기가 있습니다
숨겨 둔 것도 있어요

일기장에는 일부러 심어 놓은 규칙이 몇 개 있습니다. 그냥 읽으면 잘 안 보이는데 AI에게 물으면 찾아냅니다. 미션 9·10·11에서 찾게 됩니다.

5-1

이렇게 시작하세요

  1. 맨 위 FILE 1 · 연습용 일기장을 내려받아 컴퓨터에 저장합니다.
  2. notebook.google.com → 로그인 → 새 노트북 만들기 → 일기장 PDF를 끌어다 놓습니다.
  3. 가운데 칸에 뜬 자동 요약부터 읽어 봅니다. 48편의 일기를 몇 줄로 어떻게 정리했는지 보는 것도 공부입니다.
미션 푸는 방법
  • 보라색 상자의 질문을 복사해서 채팅 칸에 그대로 붙여 넣습니다.
  • 답이 나오면 확인할 것을 읽고, 답에 붙은 작은 숫자를 눌러 원본 일기와 맞춰 봅니다.
  • 정답 보기는 직접 확인한 다음에 펼치세요. 먼저 보면 연습이 안 됩니다.

사진 PDF라 글자를 못 읽는다가능하면 글자로 된 원본 PDF를 구해서 올리기

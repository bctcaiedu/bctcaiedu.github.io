Overview

과정 개요

이 과정이 끝나면 텔레그램으로 “오늘 매출 알려줘”라고 보내면 AI가 답하는 카페 사장님 비서를 직접 만들어 보게 됩니다.

WHO
AI응용소프트웨어과 수강생코딩 경험이 없어도 되고, 마우스·키보드와 메신저만 쓸 줄 알면 됩니다.
GOAL
에이전트의 구조 이해“생각하는 두뇌(LLM)”, “손발(도구)”, “대화 창구(메신저)”를 직접 조립합니다.
RESULT
텔레그램 카페 비서매출 조회, 품절 처리, 지출 등록, 신메뉴 등록을 대화로 처리합니다.

사용하는 도구 한눈에 보기 클릭하면 자세히

본문에서 을 누르면 그 도구가 무엇이고 이 과정에서 어떤 역할을 하는지 설명 창이 열립니다.

Step 0

사전 준비

수업 전에 PC 사양 점검, 프로그램 설치, 계정 생성까지 끝내 두면 수업 시간을 실습에만 쓸 수 있습니다. 가장 중요한 것은 PC 메모리(RAM)입니다.

PC 사양

항목최소권장사용 모델
운영체제Windows 10 64비트Windows 11-
메모리(RAM)16GB32GB16GB: qwen3:4b, 32GB: qwen3:8b
그래픽카드없어도 됨NVIDIA 8GB 이상있으면 답변이 5~10배 빨라짐

  • 그래픽카드가 없는 PC는 첫 답변에 1~3분이 걸릴 수 있습니다. 실습실 PC가 느리면 강사 PC 한 대를 Ollama 서버로 쓰고 학생들이 여기에 접속하는 방식도 있습니다(FAQ 참고).

설치할 프로그램

  1. Python 3.12: python.org/downloads에서 받습니다. 설치 첫 화면에서 “Add python.exe to PATH”에 꼭 체크하세요.
  2. Git for Windows: git-scm.com에서 받아 기본값으로 설치합니다. Hermes 설치에 필요합니다.
  3. Ollama: ollama.com/download에서 Windows용을 받습니다(1단계에서 자세히).
  4. Google Antigravity: antigravity.google에서 Windows용을 받고, 처음 실행할 때 Google 계정으로 로그인합니다.
  5. 텔레그램: 휴대폰에 텔레그램 앱을 설치합니다. PC에서도 쓰려면 Telegram Desktop을 설치합니다(선택).

카카오톡 보충 실습을 할 때만 터널 프로그램 cloudflared를 추가로 설치합니다(보충 참고).

Step 1 · 1차시

Ollama에 Qwen 두뇌 설치하기

이 단계가 끝나면 인터넷 요금 없이 내 PC에서 돌아가는 AI(Qwen)와 한국어로 대화할 수 있습니다. Ollama는 AI 모델을 내려받아 실행해 주는 프로그램이고, Qwen은 알리바바가 무료로 공개한 AI 모델입니다.

1-1Ollama 설치

  1. ollama.com/download에서 Download for Windows를 눌러 설치합니다.
  2. 설치가 끝나면 화면 오른쪽 아래 작업표시줄에 라마 아이콘이 생깁니다.
  3. PowerShell을 열고 설치를 확인합니다.
PowerShell
ollama --version

1-2Qwen 모델 내려받기

PC 메모리에 맞는 모델을 고릅니다. 두 모델 모두 도구 호출(tools)을 지원해서 에이전트에 쓸 수 있습니다.

PC 메모리모델내려받는 크기
16GBqwen3:4b약 2.5GB
32GB 이상qwen3:8b약 5GB
PowerShell
ollama pull qwen3:4b

내려받은 뒤 바로 대화해 봅니다. 끝낼 때는 /bye를 입력합니다.

PowerShell
ollama run qwen3:4b "카페 사장님께 아침 인사를 한 줄로 해 줘"

1-3대화 기억 길이 늘리기 (필수)

Ollama는 기본으로 짧은 대화만 기억하도록 설정돼 있어서, Hermes가 요구하는 64,000토큰으로 늘린 모델을 따로 만듭니다. 이 설정을 빼면 Hermes가 시작할 때 모델을 거부합니다.

  1. 메모장을 열고 아래 두 줄을 적습니다. qwen3:8b를 쓰면 첫 줄을 바꿉니다.
Modelfile
FROM qwen3:4b
PARAMETER num_ctx 65536
  1. C:\cafe-ai 폴더를 만들고 파일 이름을 Modelfile로 저장합니다. 파일 형식을 “모든 파일”로 바꿔야 .txt가 붙지 않습니다.
  2. PowerShell에서 새 모델을 만듭니다.
PowerShell
cd C:\cafe-ai
ollama create qwen3-cafe -f Modelfile
  1. ollama list에 qwen3-cafe가 보이면 성공입니다. 이후 단계에서는 이 이름만 씁니다.

1-4메모리 아끼기 16GB PC 권장

대화 기억을 길게 하면 메모리를 많이 씁니다. 아래 설정을 하면 품질 손실은 거의 없이 메모리 사용이 절반 가까이 줄어듭니다.

PowerShell
setx OLLAMA_FLASH_ATTENTION 1
setx OLLAMA_KV_CACHE_TYPE q8_0
setx OLLAMA_KEEP_ALIVE 24h

설정 후 작업표시줄의 Ollama 아이콘을 오른쪽 클릭해 Quit하고 다시 실행합니다. OLLAMA_KEEP_ALIVE는 모델을 메모리에 계속 올려 두는 설정이라, 텔레그램 질문마다 모델을 다시 불러오는 시간을 없앱니다.

ollama run qwen3-cafe "안녕"에 한국어로 답하고, 다른 창에서 ollama ps를 쳤을 때 CONTEXT가 65536으로 보이면 됩니다.

Step 2 · 2차시

Antigravity로 카페 도구(MCP 서버) 만들기

AI 비서의 “손발”을 만듭니다. 카페 장부(데이터베이스)와, 그 장부를 읽고 쓰는 도구 5개를 Antigravity에 한국어로 부탁해서 만듭니다. MCP는 AI가 도구를 쓸 수 있게 해 주는 표준 연결 규격으로, “AI용 USB 단자”라고 설명하면 쉽습니다.

2-1프로젝트 폴더 열기

  1. Antigravity를 실행하고 Open Folder로 C:\cafe-ai 폴더를 엽니다.
  2. 에이전트 대화창을 엽니다. 모드는 처음에 Planning을 고르면 무엇을 만들지 계획을 먼저 보여 주어 설명하기 좋습니다.
  3. 에이전트가 명령어 실행이나 파일 생성을 물으면 내용을 읽어 보고 승인(Accept)합니다.

2-2프롬프트 ① 카페 장부 만들기

아래 내용을 그대로 복사해 에이전트 대화창에 붙여넣습니다.

PROMPT ①
파이썬으로 작은 카페 관리 프로그램을 만들어줘. 초보자가 읽을 수 있게 주석은 한국어로 자세히 달아줘.

1. 이 폴더에 파이썬 가상환경(.venv)을 만들어줘.
2. cafe_db.py 파일을 만들고 sqlite3로 cafe.db 데이터베이스를 만들어줘.
   - menu 테이블: id, 이름, 카테고리(커피/음료/디저트), 가격, 품절여부
   - sales 테이블: id, 날짜, 메뉴이름, 수량, 금액
   - expense 테이블: id, 날짜, 항목, 금액, 메모
3. 처음 실행할 때 샘플 데이터를 넣어줘.
   - 메뉴 10개(아메리카노 4500원, 카페라떼 5000원 등 한국 카페 메뉴)
   - 오늘과 지난 6일치 판매 기록을 하루 15~30건씩
   - 지출 3건(원두, 우유, 컵)
4. 함수 5개를 만들어줘: 메뉴 목록 보기, 품절 처리/해제, 날짜별 매출 요약(총매출, 건수, 지출, 순이익, 많이 팔린 메뉴 3개), 지출 등록, 신메뉴 등록.
5. 끝나면 함수를 직접 실행해서 오늘 매출 요약이 제대로 나오는지 보여줘.

폴더에 cafe_db.py와 cafe.db가 생기고, “오늘 총매출 OOO원” 같은 결과가 나오면 성공입니다.

2-3프롬프트 ② MCP 서버로 만들기

PROMPT ②
cafe_db.py의 함수 5개를 AI 에이전트가 쓸 수 있도록 MCP 서버로 만들어줘.

- 파일 이름: cafe_mcp.py
- .venv에 mcp 패키지를 설치해줘. (pip install mcp)
- mcp 2.x 버전이면 "from mcp.server.mcpserver import MCPServer"를 쓰고,
  1.x 버전이면 "from mcp.server.fastmcp import FastMCP"를 써줘. 설치된 버전을 먼저 확인해.
- 서버 이름은 "cafe", 실행 방식은 stdio.
- 도구 이름은 영어(get_menu, set_soldout, get_sales_report, add_expense, add_menu)로,
  도구 설명(docstring)은 한국어로 자세히 써줘. AI는 이 설명을 보고 도구를 고른다.
- 날짜를 생략하면 오늘로 처리해줘.
- 어느 폴더에서 실행해도 cafe.db를 찾도록 파일 위치 기준 절대경로를 써줘.
- 마지막으로 도구 목록을 출력하는 간단한 테스트 스크립트 test_mcp.py도 만들고 실행해줘.

test_mcp.py 실행 결과에 도구 5개 이름이 보이면 성공입니다.

도구 설명을 얼마나 자세히 쓰느냐에 따라 작은 모델(Qwen 4B)의 정확도가 크게 달라집니다. “품절 처리는 메뉴 이름을 정확히 넣어야 하며, 모르면 먼저 get_menu로 확인하라”처럼 쓰는 것이 좋습니다.

만들어진 코드는 학생마다 조금씩 다릅니다. 수업을 맞추려면 강사가 미리 만든 완성본을 나눠 주고, 안 되는 학생은 그 파일로 바꿔 진행합니다.

mcp 패키지는 2.x에서 FastMCP가 MCPServer로 이름이 바뀌었습니다. No module named 'mcp.server.fastmcp' 오류가 나면 오류 문구를 그대로 에이전트에게 보여 주면 고칩니다.

Step 3 · 3차시

Hermes 에이전트에 두뇌와 손발 연결하기

이 단계가 끝나면 PowerShell에서 hermes에게 “오늘 매출 알려줘”라고 하면, Qwen이 카페 도구를 골라 실행하고 답합니다. Hermes는 Nous Research가 만든 무료 오픈소스 에이전트입니다.

3-1Hermes 설치

PowerShell에서 아래 한 줄을 실행합니다. 설치가 끝나면 PowerShell 창을 닫고 새로 열어야 hermes 명령을 쓸 수 있습니다.

PowerShell
iex (irm https://raw.githubusercontent.com/NousResearch/hermes-agent/main/scripts/install.ps1)

3-2Qwen(Ollama)을 두뇌로 지정

PowerShell
hermes setup

설정 마법사가 물어보면 아래처럼 답합니다.

질문입력값
Provider(제공자)Custom Endpoint
Base URLhttp://localhost:11434/v1
API Key비워 두거나 no-key
Modelqwen3-cafe (1단계에서 만든 이름)

로컬 모델은 답이 느리므로 기다리는 시간을 늘려 둡니다. 메모장으로 %LOCALAPPDATA%\hermes\.env 파일을 열고 맨 아래에 한 줄을 추가합니다.

.env
HERMES_API_TIMEOUT=1800

3-3카페 도구(MCP) 연결

메모장으로 %LOCALAPPDATA%\hermes\config.yaml을 열고 파일 맨 아래에 다음을 붙여넣습니다. 띄어쓰기(들여쓰기)가 틀리면 읽지 못하니 그대로 복사하세요.

config.yaml
mcp_servers:
  cafe:
    command: "C:\\cafe-ai\\.venv\\Scripts\\python.exe"
    args: ["C:\\cafe-ai\\cafe_mcp.py"]
    cwd: "C:\\cafe-ai"
    env:
      PYTHONUTF8: "1"

# 작은 모델이 헷갈리지 않도록 카페 도구만 켭니다
platform_toolsets:
  cli: [cafe]
  telegram: [cafe]

platform_toolsets는 에이전트가 쓸 수 있는 도구를 카페 도구로만 제한하는 설정입니다. 두 가지 이유로 꼭 넣습니다.

  • 속도와 정확도: Hermes는 기본으로 터미널, 파일, 웹 검색 등 도구를 수십 개 켭니다. 작은 모델은 도구가 많을수록 느려지고 잘못 고릅니다.
  • 보안: 5단계에서 연결하는 텔레그램에 터미널 도구가 켜져 있으면, 메시지로 PC에 명령을 내릴 수 있게 됩니다.

연결을 확인합니다. 도구 5개가 보이면 성공입니다.

PowerShell
hermes mcp test cafe

3-4사장님 비서 성격 입히기 (SOUL.md)

%LOCALAPPDATA%\hermes\SOUL.md 파일은 에이전트의 성격과 말투를 정합니다. 원래 파일은 SOUL.md.bak으로 복사해 두고, 내용을 아래처럼 바꿉니다. 학생마다 자기 카페 이름으로 바꿔 보게 하면 좋습니다.

SOUL.md
당신은 '햇살카페' 사장님의 다정한 경영 비서입니다.
- 항상 존댓말로, 3~4문장 이내로 짧게 답합니다.
- 매출·메뉴·지출은 반드시 cafe 도구로 확인한 값만 말합니다. 추측하지 않습니다.
- 금액은 "12,500원"처럼 쉼표를 넣어 말합니다.
- 품절 처리나 지출 등록처럼 장부를 바꾸는 일은 한 뒤 무엇을 바꿨는지 알려 드립니다.

3-5첫 대화

PowerShell
hermes

아래 세 문장을 차례로 입력해 봅니다.

  1. 오늘 매출 요약해 줘
  2. 카페라떼 품절 처리해 줘
  3. 우유 32,000원 지출 등록해 줘

답변 위에 get_sales_report처럼 도구 이름이 보이고, 금액이 2단계에서 확인한 값과 같으면 성공입니다. 도구 이름 없이 숫자를 말하면 AI가 지어낸 것이니, “도구로 확인해서 다시 알려줘”라고 해 봅니다. 이 차이를 학생들에게 직접 보여 주면 “AI가 도구를 쓴다”는 개념이 분명해집니다.

Step 4 · 4차시

텔레그램 봇 만들기

텔레그램에서는 누구나 1분 만에 무료로 봇을 만들 수 있습니다. 텔레그램 공식 봇인 @BotFather에게 말을 걸어 봇을 만들고, 봇을 조종하는 열쇠인 봇 토큰을 받습니다.

4-1BotFather로 봇 만들기

  1. 텔레그램에서 @BotFather를 검색하거나 t.me/BotFather를 엽니다. 이름 옆에 파란 공식 인증 표시가 있는지 확인합니다.
  2. 시작(Start)을 누르고 /newbot을 보냅니다.
  3. 봇의 표시 이름을 정합니다. 예: 햇살카페 비서
  4. 봇의 아이디를 정합니다. 영어로 쓰고 반드시 bot으로 끝나야 합니다. 예: sunny_cafe_kim_bot. 이미 있는 이름이면 다른 이름을 고릅니다.
  5. BotFather가 보내 준 긴 문자열(1234567890:AAH... 모양)이 봇 토큰입니다. 복사해서 메모장에 붙여 둡니다.

봇 토큰을 가진 사람은 누구나 내 봇을 조종할 수 있습니다. 화면 공유나 단체방에 올리지 않습니다. 실수로 공개했으면 BotFather에 /revoke를 보내 새 토큰을 받습니다.

4-2봇 꾸미기 선택

BotFather에게 아래 명령을 보내면 봇 소개와 메뉴를 바꿀 수 있습니다.

  • /setdescription 봇을 처음 열었을 때 보이는 소개 글. 예: “햇살카페 매출·메뉴·지출을 관리하는 AI 비서입니다.”
  • /setuserpic 봇 프로필 사진
  • /setcommands 입력창의 메뉴 버튼. 아래 내용을 붙여넣습니다.
BotFather /setcommands
new - 새 대화 시작
status - 현재 대화 정보 보기
stop - 진행 중인 작업 멈추기
help - 도움말

4-3내 텔레그램 사용자 ID 알아내기

내 봇을 나만 쓰게 하려면 숫자로 된 사용자 ID가 필요합니다. @username과는 다른 값입니다.

  1. 텔레그램에서 @userinfobot을 검색하거나 t.me/userinfobot을 엽니다.
  2. 아무 메시지나 보내면 Id: 123456789 같은 숫자를 알려 줍니다. 이 숫자를 메모장에 적어 둡니다.

메모장에 봇 토큰과 내 사용자 ID 두 가지가 적혀 있고, 텔레그램에서 내 봇을 검색해 대화방을 열 수 있으면 됩니다. 아직은 봇이 답하지 않습니다.

Step 5 · 4차시

Hermes와 텔레그램 연결하기

Hermes에는 텔레그램 연결 기능이 들어 있어서 설정 두 줄과 명령 한 줄이면 연결됩니다. Hermes가 텔레그램 서버에서 새 메시지를 직접 가져오는 방식이라, 카카오톡처럼 인터넷 주소(터널)나 중계 서버를 만들 필요가 없습니다.

5-1봇 토큰과 사용자 ID 등록

방법은 두 가지입니다. 처음에는 마법사(방법 A)가 쉽습니다.

방법 A. 설정 마법사: 아래 명령을 실행하고 화살표 키로 Telegram을 고른 뒤, 4단계에서 적어 둔 봇 토큰과 사용자 ID를 붙여넣습니다.

PowerShell
hermes gateway setup

방법 B. 직접 입력: 메모장으로 %LOCALAPPDATA%\hermes\.env를 열고 맨 아래에 두 줄을 추가합니다.

.env
TELEGRAM_BOT_TOKEN=1234567890:AAH여기에봇토큰
TELEGRAM_ALLOWED_USERS=123456789

TELEGRAM_ALLOWED_USERS는 이 봇과 대화할 수 있는 사람 목록입니다. 직원도 쓰게 하려면 123456789,987654321처럼 쉼표로 이어 적습니다.

5-2텔레그램에서도 카페 도구만 쓰게 하기

3-3에서 config.yaml에 넣은 platform_toolsets에 telegram: [cafe]가 있는지 다시 확인합니다. 이 줄이 빠지면 텔레그램 메시지로 터미널, 파일, 웹 검색 같은 기본 도구까지 쓸 수 있게 됩니다.

config.yaml
platform_toolsets:
  cli: [cafe]
  telegram: [cafe]

5-3게이트웨이 실행

Hermes가 텔레그램을 지켜보며 답하는 상태를 게이트웨이라고 합니다. 이 창은 수업 내내 켜 둡니다.

PowerShell
hermes gateway

화면에 Telegram adapter connected가 보이면 연결된 것입니다.

5-4휴대폰으로 첫 대화

  1. 텔레그램에서 내 봇 대화방을 열고 시작(Start)을 누릅니다.
  2. “오늘 매출 요약해 줘”를 보냅니다. 로컬 모델이라 답이 오기까지 10초~2분이 걸릴 수 있습니다. 상단에 “입력 중…”이 보이면 생각하고 있는 것입니다.
  3. 대화를 처음부터 다시 하고 싶으면 /new를 보냅니다.

휴대폰 텔레그램에서 매출 답변이 오고, PowerShell 창에 get_sales_report 도구를 쓴 기록이 보이면 성공입니다. 허용 목록에 없는 다른 학생이 내 봇에 말을 걸면 답하지 않는지도 확인합니다.

여러 명이 쓰게 하려면: 허용 목록을 매번 고치는 대신 페어링을 쓸 수 있습니다. 목록에 없는 사람이 봇에게 말을 걸면 일회용 코드가 오고, 사장님 PC에서 hermes pairing approve telegram 코드를 실행하면 바로 등록됩니다. 등록된 사람은 hermes pairing list로 확인합니다.

PC를 끄면 봇도 멈춥니다. Hermes와 cafe.db가 모두 이 PC에 있기 때문입니다. 실제 매장에서 쓰려면 항상 켜 두는 PC나 서버가 필요하다는 점을 설명해 줍니다.

Step 6 · 6차시

통합 테스트와 시연

휴대폰 텔레그램으로 아래 시나리오를 순서대로 진행하고, 장부가 실제로 바뀌었는지 확인합니다. 시작 전에 Ollama와 Hermes 게이트웨이가 켜져 있는지부터 점검합니다.

시작 전 점검

  • Ollama 아이콘이 작업표시줄에 있다
  • hermes gateway 창에 Telegram adapter connected가 보인다
  • config.yaml의 platform_toolsets에 telegram: [cafe]가 있다
  • 휴대폰 텔레그램에서 내 봇 대화방이 열린다

시연 시나리오

순서텔레그램에 보낼 말AI가 쓸 도구제대로 됐는지 확인하는 법
1오늘 매출 요약해 줘get_sales_report금액이 2단계 테스트 결과와 같다
2메뉴 중에 제일 비싼 게 뭐야?get_menu실제 메뉴판과 같다
3카페라떼 품절 처리해 줘set_soldout2번을 다시 물어보면 품절로 나온다
4우유 32,000원 지출 등록해 줘add_expense1번을 다시 물어보면 지출이 32,000원 늘었다
5딸기라떼 6,000원으로 신메뉴 등록해 줘add_menu2번을 다시 물어보면 딸기라떼가 있다
6아까 품절시킨 메뉴 다시 팔아 줘set_soldout앞의 대화를 기억해서 카페라떼를 해제한다

6번은 사용자별 대화 기억(conversation)이 동작하는지 보는 문제입니다. 다른 학생의 휴대폰으로 내 봇에 말을 걸어 답하지 않는지도 확인하면 보안 설명으로 이어집니다.

응용 과제 여유가 있을 때

  • Antigravity에 “어제와 오늘 매출을 비교하는 도구를 추가해 줘”라고 요청하고, hermes gateway를 다시 켜서 텔레그램으로 시험합니다.
  • SOUL.md의 말투를 “사투리를 쓰는 정감 있는 비서”로 바꿔 보고 차이를 비교합니다.
  • 같은 질문을 qwen3:4b와 qwen3:8b에 해 보고 속도와 정확도를 비교합니다.
  • 텔레그램에 영수증 사진을 보내고 “이 지출 등록해 줘”라고 해 봅니다. 사진을 이해하는 모델이 필요해서 Qwen3로는 잘 안 되는데, 왜 그런지 토론해 봅니다.

강사 팁

  • 강사 PC를 공용 두뇌로: 실습실 PC가 약하면, 그래픽카드가 있는 강사 PC에서 setx OLLAMA_HOST 0.0.0.0을 설정하고 Ollama를 다시 켭니다. 학생은 3-2의 Base URL을 http://강사PC의IP:11434/v1로 넣습니다. 실습실 내부망에서만 쓰고 수업이 끝나면 설정을 지웁니다.
  • 진도를 맞추는 법: 단계마다 완성본 폴더(step2, step5 등)를 USB나 공유 폴더로 나눠 주면 뒤처진 학생도 다음 단계에 합류할 수 있습니다.
  • 비유로 설명하기: LLM은 “두뇌”, MCP 도구는 “손발”, Hermes는 “두뇌와 손발을 잇는 비서실장”, 텔레그램은 “전화기”, 봇 토큰은 “전화기 열쇠”입니다.
  • Antigravity 사용량 한도: 무료 계정은 사용량에 한도가 있어서, 한 학생이 같은 요청을 여러 번 반복하면 잠시 막힐 수 있습니다. 막히면 완성본 파일로 진행합니다. 개강 전에 공식 사이트에서 무료 조건을 다시 확인하세요.

보안 주의 수업에서 꼭 강조

  • 허용 목록(TELEGRAM_ALLOWED_USERS)을 꼭 쓴다: 텔레그램 봇은 아이디만 알면 누구나 검색해서 말을 걸 수 있어서, 목록이 없으면 모르는 사람이 장부를 바꿀 수 있습니다.
  • 도구는 카페 도구만 켠다: platform_toolsets의 telegram: [cafe]를 빼면 텔레그램 메시지로 PC에 명령을 내릴 수 있게 됩니다.
  • 봇 토큰은 비밀번호처럼: 화면 공유나 단체방에 올리지 않고, 새어 나가면 BotFather의 /revoke로 바로 바꿉니다.
  • 수업이 끝나면 게이트웨이를 끈다: hermes gateway 창에서 Ctrl+C를 누릅니다.
  • 실습 데이터는 가짜로: 실제 매장 매출이나 개인정보는 넣지 않습니다.

보충. 카카오톡으로 연결하기

본 과정의 텔레그램 대신 카카오톡으로 비서와 대화하고 싶을 때 따라 하는 보충 실습입니다. Hermes는 카카오톡을 직접 지원하지 않아서, 카카오 i 오픈빌더와 우리가 만든 중계 서버, 내 PC를 인터넷에 여는 Cloudflare 터널이 추가로 필요합니다.

비교텔레그램 (본 과정)카카오톡 (보충)
봇 만들기BotFather에서 1분, 심사 없음카카오 채널 + 오픈빌더, 콜백 심사 필요
Hermes 지원기본 지원 (hermes gateway)지원 안 함 → 중계 서버 직접 제작
인터넷 주소필요 없음 (PC가 메시지를 가져옴)필요 (카카오가 PC로 보냄) → 터널
응답 시간 제한제한 없음5초, 콜백 사용 시 5분
켜 둘 창1개 (게이트웨이)3개 (게이트웨이, 중계 서버, 터널)

추가로 준비할 것

  • 카카오 비즈니스 계정: business.kakao.com에 카카오계정으로 가입
  • 터널 프로그램 설치: PowerShell에서 winget install --id Cloudflare.cloudflared
  • 1주 전: K-2의 AI 챗봇 콜백 신청. 승인이 늦어지면 K-5의 “결과” 물어보기 방식으로 진행합니다(승인 불필요).

카카오 화면 구성은 자주 바뀌므로 수업 전에 강사가 한 번 따라 해 보고 메뉴 이름을 맞춰 두세요.

K-1카카오톡 채널 만들기

  1. business.kakao.com에 카카오계정으로 로그인합니다.
  2. 카카오톡 채널 만들기에서 채널 이름(예: 햇살카페 비서)과 검색용 아이디를 정합니다.
  3. 채널 관리자센터에서 채널을 공개로 두고 채팅 기능을 켭니다.

K-2오픈빌더에서 챗봇 만들기

  1. chatbot.kakao.com에 접속해 봇 만들기 → 카카오톡 챗봇을 고릅니다.
  2. 봇 설정에서 K-1의 카카오톡 채널을 연결합니다.
  3. 같은 설정 화면에서 AI 챗봇 전환(콜백 기능) 신청을 합니다. 사용 목적에는 “로컬 LLM 기반 카페 경영 비서 교육 실습”처럼 적습니다.

콜백이 필요한 이유: 오픈빌더는 스킬 서버가 5초 안에 답하지 않으면 오류로 처리합니다. 내 PC의 Qwen은 보통 10초~2분이 걸리므로, 먼저 “잠시만요”로 답하고 나중에 결과를 보내는 콜백 기능을 씁니다. 콜백 주소는 5분간 유효하고 한 번만 쓸 수 있습니다(카카오 콜백 가이드).

K-3스킬 등록과 폴백 블록 연결

아래 작업은 K-7에서 터널 주소를 받은 뒤에 합니다.

  1. 스킬 → 생성에서 이름을 카페비서로, URL을 https://(터널주소)/kakao/skill로 넣고 저장합니다.
  2. 시나리오 → 폴백 블록을 엽니다. 폴백 블록은 다른 블록에 해당하지 않는 모든 말을 받습니다.
  3. 파라미터 설정에서 스킬을 카페비서로 고르고, 봇 응답을 스킬데이터 사용으로 바꿉니다.
  4. 콜백이 승인되었다면 블록 오른쪽 위 더보기(…) → Callback API 설정을 켜고 기본 응답에 “장부를 확인하고 있어요. 잠시만 기다려 주세요”를 적습니다.
  5. 배포 메뉴에서 배포합니다. 배포하지 않으면 오픈빌더 테스트 창에서만 동작하고 실제 채널에서는 반영되지 않습니다.

휴대폰 카카오톡에서 채널을 찾아 채팅방을 열 수 있으면 됩니다. 답장은 K-8까지 끝나야 옵니다.

K-4Hermes를 API 서버로 켜기

%LOCALAPPDATA%\hermes\.env 맨 아래에 두 줄을 추가합니다. 비밀번호는 아무 긴 문자열로 직접 정하고, 남에게 보여주지 않습니다.

.env
API_SERVER_ENABLED=true
API_SERVER_KEY=내가정한긴비밀번호

창 ①에서 Hermes를 실행합니다. API server listening on http://127.0.0.1:8642가 보이면 성공이고, 이 창은 수업 내내 켜 둡니다.

창 ① PowerShell
hermes gateway

API 서버로 들어온 질문도 카페 도구만 쓰도록 config.yaml의 platform_toolsets에 api_server: [cafe] 한 줄을 추가하고 게이트웨이를 다시 켭니다. 이 줄이 없으면 카카오톡 메시지로 PC에 명령을 내릴 수 있게 됩니다.

config.yaml
platform_toolsets:
  cli: [cafe]
  telegram: [cafe]
  api_server: [cafe]

K-5프롬프트 ③ 중계 서버 만들기

Antigravity 에이전트 대화창에 붙여넣습니다.

PROMPT ③
카카오 i 오픈빌더 스킬 서버를 FastAPI로 만들어줘. 파일 이름은 kakao_bridge.py.

- .venv에 fastapi, uvicorn, httpx를 설치해줘.
- POST /kakao/skill 로 요청을 받는다. 사용자 ID는 userRequest.user.id,
  질문은 userRequest.utterance, 콜백 주소는 userRequest.callbackUrl 에 있다.
- 질문은 Hermes API 서버(http://127.0.0.1:8642/v1/responses)에 보낸다.
  헤더 Authorization: Bearer (환경변수 HERMES_KEY),
  본문 {"model":"hermes-agent","input":질문,"conversation":"kakao-"+사용자ID,"store":true}.
  답은 응답의 output 목록에서 type이 message인 항목의 output_text 글자다.
- 환경변수 ALLOWED_USERS(쉼표 구분)에 없는 사용자에게는 "등록된 사장님만 사용할 수 있어요"와
  그 사람의 ID를 알려주고, Hermes에는 보내지 마.
- callbackUrl이 있으면: 즉시 {"version":"2.0","useCallback":true,"data":{"text":"잠시만 기다려 주세요"}}
  를 돌려주고, 백그라운드에서 Hermes 답을 받아 callbackUrl로 POST 한다.
- callbackUrl이 없으면: "30초쯤 뒤에 '결과'라고 보내 주세요"라고 답하고 백그라운드에서
  답을 저장해 두었다가, 사용자가 "결과"라고 보내면 꺼내 준다.
- 카카오 답장은 simpleText 형식, 1000자를 넘으면 자른다.
- Hermes가 꺼져 있으면 오류 대신 "비서가 응답하지 못했어요"라고 답한다.
- 요청이 올 때마다 사용자 ID와 질문을 화면에 출력해줘.
- 마지막으로 가짜 카카오 요청을 보내는 테스트를 만들어 실행해줘.

에이전트가 만든 코드가 동작하지 않으면 아래 강사용 완성본을 C:\cafe-ai\kakao_bridge.py로 저장해 씁니다. 이 코드는 가짜 Hermes로 네 가지 경우(미등록 사용자 거부, 콜백 응답, “결과” 물어보기, Hermes 꺼짐)를 테스트했습니다.

강사용 완성본 kakao_bridge.py 펼치기
Python
"""카카오톡 ↔ Hermes 중계 서버
실행: .venv\Scripts\python -m uvicorn kakao_bridge:app --port 8000
"""
import os

import httpx
from fastapi import BackgroundTasks, FastAPI, Request

HERMES_URL = os.getenv("HERMES_URL", "http://127.0.0.1:8642")
HERMES_KEY = os.getenv("HERMES_KEY", "")
# 쉼표로 구분한 카카오 사용자 ID 목록. 여기 없는 사람에게는 "내 ID"만 알려줍니다.
ALLOWED_USERS = [u.strip() for u in os.getenv("ALLOWED_USERS", "").split(",") if u.strip()]

app = FastAPI()
results = {}  # 콜백 미승인 시 사용자별 답변 보관 ("결과" 물어보기 방식)


def kakao_text(text: str) -> dict:
    """카카오 말풍선(simpleText) 응답. 말풍선은 1000자까지만 보입니다."""
    return {"version": "2.0", "template": {"outputs": [{"simpleText": {"text": text[:1000]}}]}}


def ask_hermes(user_id: str, question: str) -> str:
    """Hermes에게 질문하고 최종 답변 글자만 꺼냅니다."""
    try:
        r = httpx.post(
            f"{HERMES_URL}/v1/responses",
            headers={"Authorization": f"Bearer {HERMES_KEY}"},
            json={"model": "hermes-agent", "input": question,
                  "conversation": f"kakao-{user_id}",  # 사용자별로 대화를 이어감
                  "store": True},
            timeout=280,  # 콜백 주소는 5분간 유효하므로 그 안에 끝냅니다
        )
        r.raise_for_status()
    except Exception as e:
        return f"비서가 응답하지 못했어요. Hermes가 켜져 있는지 확인해 주세요. ({type(e).__name__})"

    answer = ""
    for item in r.json().get("output", []):
        if item.get("type") == "message" and item.get("phase") != "commentary":
            for part in item.get("content", []):
                if part.get("type") == "output_text":
                    answer = part.get("text", "")
    return answer or "답변이 비어 있어요. 다시 한 번 물어봐 주세요."


def answer_by_callback(callback_url: str, user_id: str, question: str):
    """콜백 방식: 다 생각한 뒤 카카오가 준 콜백 주소로 답을 보냅니다."""
    httpx.post(callback_url, json=kakao_text(ask_hermes(user_id, question)), timeout=10)


def answer_later(user_id: str, question: str):
    """'결과' 물어보기 방식: 답을 보관해 두었다가 물어보면 꺼내 줍니다."""
    results[user_id] = ask_hermes(user_id, question)


@app.post("/kakao/skill")
async def kakao_skill(request: Request, background: BackgroundTasks):
    body = await request.json()
    user_req = body.get("userRequest", {})
    user_id = user_req.get("user", {}).get("id", "")
    question = user_req.get("utterance", "").strip()
    callback_url = user_req.get("callbackUrl")
    print(f"[카카오] 사용자={user_id} 질문={question!r} 콜백={'있음' if callback_url else '없음'}")

    # 1. 허용된 사장님만 사용
    if user_id not in ALLOWED_USERS:
        return kakao_text(f"등록된 사장님만 사용할 수 있어요.\n내 ID: {user_id}")

    # 2. 콜백 승인된 경우: "잠시만요" 먼저, 답은 나중에 콜백으로
    if callback_url:
        background.add_task(answer_by_callback, callback_url, user_id, question)
        return {"version": "2.0", "useCallback": True,
                "data": {"text": "장부를 확인하고 있어요. 잠시만 기다려 주세요."}}

    # 3. 콜백이 없는 경우: "결과"라고 물어보면 보관해 둔 답을 보여줌
    if question == "결과":
        if user_id not in results:
            return kakao_text("먼저 궁금한 것을 물어봐 주세요.")
        if results[user_id] is None:
            return kakao_text("아직 생각하고 있어요. 조금 뒤에 다시 '결과'라고 보내 주세요.")
        return kakao_text(results.pop(user_id))

    results[user_id] = None  # 생각 중 표시
    background.add_task(answer_later, user_id, question)
    return kakao_text("질문을 받았어요. 30초쯤 뒤에 '결과'라고 보내 주세요.")

K-6중계 서버 실행

창 ②에서 실행합니다. HERMES_KEY에는 K-4에서 정한 비밀번호를 넣습니다. ALLOWED_USERS는 처음에는 비워 둡니다.

창 ② PowerShell
cd C:\cafe-ai
$env:HERMES_KEY = "내가정한긴비밀번호"
$env:ALLOWED_USERS = ""
.venv\Scripts\python -m uvicorn kakao_bridge:app --port 8000

K-7터널로 인터넷에 연결

카카오 서버는 인터넷에 있고 중계 서버는 내 PC 안에 있어서, 터널로 “임시 인터넷 주소”를 만듭니다. 창 ③에서 실행합니다.

창 ③ PowerShell
cloudflared tunnel --url http://localhost:8000

화면에 나오는 https://임의의단어들.trycloudflare.com 주소를 복사해, K-3 스킬 URL에 https://임의의단어들.trycloudflare.com/kakao/skill로 넣고 배포합니다.

이 주소는 터널을 다시 켤 때마다 바뀝니다. 그때마다 스킬 URL을 고치고 다시 배포해야 합니다.

K-8내 카카오 ID 등록하기

  1. 휴대폰 카카오톡에서 내 채널에 “안녕”을 보냅니다.
  2. “등록된 사장님만 사용할 수 있어요. 내 ID: …”라는 답이 오면 ID를 복사합니다. 창 ②에도 같은 ID가 찍힙니다.
  3. 창 ②에서 Ctrl+C로 중계 서버를 멈추고, $env:ALLOWED_USERS = "복사한 ID"를 넣은 뒤 다시 실행합니다.

오픈빌더 테스트 창과 실제 카카오톡은 사용자 ID가 다릅니다. 둘 다 쓰려면 두 ID를 쉼표로 이어 적습니다.

카카오톡에 “오늘 매출 알려줘”를 보내면 “잠시만 기다려 주세요” 뒤에 매출 답변이 옵니다. 콜백 승인 전이라면 안내대로 “결과”를 보내면 답이 옵니다.

카카오톡에서 자주 생기는 문제

증상원인해결
카카오 테스트 창에 “스킬 서버 오류”터널 주소가 바뀌었거나 창 ②·③이 꺼짐새 터널 주소로 스킬 URL을 고치고 다시 배포합니다
테스트 창은 되는데 휴대폰은 안 됨배포를 안 함오픈빌더 배포 메뉴에서 배포합니다
“잠시만요” 뒤에 답이 안 옴5분 안에 답을 못 만듦창 ①에서 오류를 확인하고, 더 작은 모델을 씁니다
  • 허용 목록(ALLOWED_USERS): 카카오톡 채널은 누구나 친구 추가할 수 있으니 중계 서버의 허용 목록을 꼭 씁니다.
  • API_SERVER_KEY는 화면 공유나 카카오톡으로 보내지 않습니다.
  • 수업이 끝나면 창 세 개(게이트웨이, 중계 서버, 터널)를 모두 닫습니다. 터널이 열려 있는 동안에는 중계 서버가 인터넷에 노출됩니다.

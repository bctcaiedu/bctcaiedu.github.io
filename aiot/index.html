Basics

IoT 기본 개념

IoT(사물인터넷)는 사물에 센서와 통신을 붙여, 사람이 개입하지 않아도 데이터를 주고받고 스스로 동작하게 하는 기술입니다. AIoT는 여기에 AI를 더해, 모인 데이터로 판단까지 하는 것을 말합니다.

IoT의 4계층

계층역할이 과정에서 쓰는 것
디바이스센서로 측정하고 액추에이터로 동작휴대폰(시뮬레이터), ESP32, 센서, 카메라
네트워크데이터를 전달Wi-Fi, MQTT
플랫폼데이터를 저장하고 처리HiveMQ(클라우드 브로커), ThingSpeak(클라우드 저장소)
서비스사람에게 가치를 전달대시보드, 알림, AI 분석, LLM 리포트

Protocol

IoT 통신과 MQTT

IoT 기기는 작고, 자주, 실시간으로 말합니다. 그래서 웹의 HTTP보다 가볍고 즉시 전달되는 MQTT를 주로 씁니다.

항목HTTPMQTT
방식요청하면 응답발행(publish)하면 구독자(subscribe)에게 전달
메시지 크기크다 (헤더가 길다)작다 (수십 바이트)
실시간성서버가 먼저 보내기 어렵다연결을 유지해 즉시 전달
어울리는 곳웹페이지, 가끔 보내는 데이터센서와 기기 제어

MQTT 핵심 용어

  • 브로커 — 메시지를 중계하는 서버(우체국 역할). 이 과정에서는 클라우드에 있는 HiveMQ 공개 브로커 broker.hivemq.com을 씁니다.
  • 토픽 — 메시지의 주소. /로 계층을 나눕니다. +는 한 단계, #은 그 아래 전부를 뜻합니다.
  • QoS — 전달 보장 수준. 0(한 번 보냄), 1(최소 한 번 도착), 2(정확히 한 번).

왜 https 주소와 클라우드 브로커인가

휴대폰 브라우저는 https 주소에서만 가속도 센서와 마이크를 허용합니다. 그리고 https 페이지는 암호화된 wss:// 브로커에만 접속할 수 있습니다. 그래서 시뮬레이터는 이 사이트(GitHub Pages)에 올려 두고, 강의실 안 서버 대신 클라우드 브로커를 씁니다. 덕분에 집에서도 같은 환경으로 프로젝트를 이어갈 수 있습니다.

알아 둘 한계

  • 온도 · 습도 · 조도는 실제로 재는 값이 아닙니다. 예측 실습처럼 실제 데이터가 필요하면 ESP32 데이터나 강사 제공 샘플을 씁니다.
  • 화면이 꺼지거나 다른 앱으로 가면 전송이 멈춥니다. 실습 중에는 페이지를 켜 둡니다.
  • 진동 명령은 아이폰에서 동작하지 않습니다.

심화 과제 · ESP32로 실제 센서 읽기

DHT22 데이터 → GPIO 4, 조도 센서 → GPIO 1, LED → GPIO 5로 배선합니다(핀 번호는 보드에 맞게). 라이브러리 관리자에서 DHT sensor library(Adafruit)를 설치하고 올린 뒤, 시리얼 플로터로 시뮬레이터와 같은 값이 나오는지 비교합니다.

Arduino (C++)
#include <DHT.h>

#define DHT_PIN   4
#define LIGHT_PIN 1
#define LED_PIN   5

DHT dht(DHT_PIN, DHT22);

void setup() {
  Serial.begin(115200);
  pinMode(LED_PIN, OUTPUT);
  dht.begin();
}

void loop() {
  float temp = dht.readTemperature();
  float hum  = dht.readHumidity();
  int light  = analogRead(LIGHT_PIN);   // 0~4095

  if (isnan(temp) || isnan(hum)) {
    Serial.println("DHT 센서 읽기 실패");
  } else {
    // 시리얼 플로터용 형식: 이름:값
    Serial.printf("temp:%.1f,hum:%.1f,light:%d\n", temp, hum, light);
  }
  delay(2000);   // DHT22는 2초에 한 번 읽기
}
Lab 2

MQTT 송수신과 자동화

내 센서값을 클라우드 브로커로 보내고, 짝의 명령과 내 Python 코드로 내 LED를 제어합니다. 센서 → 브로커 → 판단 → 브로커 → 동작으로 이어지는 IoT의 기본 고리를 직접 닫아 봅니다.

STEPS보내고, 보고, 켜기
  1. 시뮬레이터에서 연결을 눌러 상태가 "연결됨"이 되는지 확인합니다.
  2. PC의 MQTT Explorer에서 Host broker.hivemq.com, Port 1883으로 접속하고, aiot-kt2611 아래에 반 전체의 센서값이 쌓이는 것을 봅니다.
  3. 짝의 LED를 켭니다. Publish에서 토픽 aiot-kt2611/s02/led, 메시지 ON(또는 #00aaff 같은 색). aiot-kt2611/s02/cmd에 BEEP을 보내면 짝의 휴대폰에서 소리가 납니다.
  4. 아래 Python 코드를 실행하고, 휴대폰의 온도 슬라이더를 28℃ 위로 올려 LED가 스스로 켜지는지 확인합니다.
명령줄로 보고 보내기 (mosquitto-clients가 있을 때)
mosquitto_sub -h broker.hivemq.com -t "aiot-kt2611/#" -v
mosquitto_pub -h broker.hivemq.com -t aiot-kt2611/s02/led -m ON
Python · lab2_auto_led.py
import json
import paho.mqtt.client as mqtt

BROKER = "broker.hivemq.com"
PREFIX = "aiot-kt2611"   # 반 코드로 바꾸기
ME = "s01"               # 내 번호

def on_message(c, userdata, msg):
    try:
        data = json.loads(msg.payload)
    except json.JSONDecodeError:
        return
    led = "ON" if data.get("temp", 0) > 28 else "OFF"
    print(data, "->", led)
    c.publish(f"{PREFIX}/{ME}/led", led)

client = mqtt.Client(mqtt.CallbackAPIVersion.VERSION2)
client.on_message = on_message
client.connect(BROKER, 1883)
client.subscribe(f"{PREFIX}/{ME}/sensor")
client.loop_forever()   # Ctrl+C로 종료

Arduino (C++)
#include <WiFi.h>
#include <PubSubClient.h>
#include <DHT.h>

const char* WIFI_SSID = "CLASS_WIFI";
const char* WIFI_PASS = "강의실비밀번호";
const char* BROKER    = "broker.hivemq.com";
const String PREFIX   = "aiot-kt2611";     // 반 코드
const String ME       = "s01";             // 내 번호

#define DHT_PIN   4
#define LIGHT_PIN 1
#define LED_PIN   5

WiFiClient wifi;
PubSubClient mqtt(wifi);
DHT dht(DHT_PIN, DHT22);
unsigned long lastSend = 0;

String topic(const char* sub) { return PREFIX + "/" + ME + "/" + sub; }

void onMessage(char* t, byte* payload, unsigned int len) {
  String msg;
  for (unsigned int i = 0; i < len; i++) msg += (char)payload[i];
  if (msg == "ON")  digitalWrite(LED_PIN, HIGH);
  if (msg == "OFF") digitalWrite(LED_PIN, LOW);
  Serial.println("수신: " + msg);
}

void connectMqtt() {
  while (!mqtt.connected()) {
    String id = "esp32-" + ME + "-" + String(random(0xffff), HEX);
    if (mqtt.connect(id.c_str())) {
      mqtt.subscribe(topic("led").c_str());
      Serial.println("MQTT 연결됨");
    } else {
      delay(2000);
    }
  }
}

void setup() {
  Serial.begin(115200);
  pinMode(LED_PIN, OUTPUT);
  dht.begin();
  WiFi.begin(WIFI_SSID, WIFI_PASS);
  while (WiFi.status() != WL_CONNECTED) delay(500);
  mqtt.setServer(BROKER, 1883);
  mqtt.setCallback(onMessage);
}

void loop() {
  if (!mqtt.connected()) connectMqtt();
  mqtt.loop();

  if (millis() - lastSend > 5000) {   // 5초마다 전송
    lastSend = millis();
    float t = dht.readTemperature();
    float h = dht.readHumidity();
    int   l = analogRead(LIGHT_PIN);
    if (isnan(t) || isnan(h)) return;
    char json[80];
    snprintf(json, sizeof(json), "{\"temp\":%.1f,\"hum\":%.1f,\"light\":%d}", t, h, l);
    mqtt.publish(topic("sensor").c_str(), json);
  }
}

// Wokwi 라이브러리 관리자에서 PubSubClient, DHT sensor library 추가
#include <WiFi.h>
#include <PubSubClient.h>
#include "DHT.h"

const char* PREFIX = "aiot-kt2611";  // ← 반 코드
const char* ME     = "s01w";         // ← 내 번호 + w (휴대폰과 겹치지 않게)
DHT dht(15, DHT22);                  // DHT22 데이터 → GPIO15
WiFiClient net;                      // 인터넷 연결 (TCP)
PubSubClient mqtt(net);              // 그 위에서 MQTT로 대화

String topic(const char* sub) { return String(PREFIX) + "/" + ME + "/" + sub; }

// 구독한 토픽에 메시지가 오면 자동으로 불리는 함수
void onMessage(char* t, byte* payload, unsigned int len) {
  Serial.print("[받음] ");
  Serial.print(t);
  Serial.print(" : ");
  for (unsigned int i = 0; i < len; i++) Serial.print((char)payload[i]);
  Serial.println();
}

// 브로커에 접속될 때까지 2초마다 다시 시도
void connectMqtt() {
  while (!mqtt.connected()) {
    String id = "esp32-" + String(random(0xffffff), HEX);  // 클라이언트 ID는 기기마다 달라야 함
    Serial.print("MQTT 접속 시도 (" + id + ") ... ");
    if (mqtt.connect(id.c_str())) {
      Serial.println("성공");
      mqtt.subscribe(topic("cmd").c_str());                // 접속할 때마다 구독도 다시
      Serial.println("구독: " + topic("cmd"));
    } else {
      Serial.print("실패, state=");
      Serial.println(mqtt.state());                        // 숫자로 실패 원인 확인
      delay(2000);
    }
  }
}

void setup() {
  Serial.begin(115200);
  dht.begin();
  WiFi.begin("Wokwi-GUEST", "", 6);                        // Wokwi의 가상 Wi-Fi
  Serial.print("Wi-Fi 연결 중");
  while (WiFi.status() != WL_CONNECTED) { delay(250); Serial.print("."); }
  Serial.println(" 연결됨, IP: " + WiFi.localIP().toString());

  mqtt.setServer("broker.hivemq.com", 1883);               // 브로커 주소와 포트
  mqtt.setCallback(onMessage);                             // 메시지가 오면 onMessage 실행
}

void loop() {
  if (!mqtt.connected()) connectMqtt();                    // 끊겼으면 다시 접속
  mqtt.loop();                                             // 받은 메시지 처리, 자주 불러야 함

  static unsigned long last = 0;
  if (millis() - last >= 5000) {                           // delay 대신 millis로 5초 세기
    last = millis();
    float t = dht.readTemperature();
    float h = dht.readHumidity();
    if (isnan(t) || isnan(h)) { Serial.println("DHT22 읽기 실패"); return; }
    char json[48];
    snprintf(json, sizeof json, "{\"temp\":%.1f,\"hum\":%.1f}", t, h);  // LAB 2와 같은 JSON
    mqtt.publish(topic("sensor").c_str(), json);
    Serial.println("[보냄] " + topic("sensor") + " : " + json);
  }
}

코드에서 꼭 알아야 할 줄

코드하는 일
mqtt.setServer("broker.hivemq.com", 1883)어느 브로커의 어느 문(포트)으로 들어갈지. ESP32는 일반 TCP 문인 1883을 씁니다.
mqtt.connect(id)브로커에 접속. 클라이언트 ID가 같은 기기가 이미 있으면 브로커가 먼저 온 쪽을 끊습니다. Wokwi의 ESP32는 모두 MAC 주소가 같아서 무작위 ID를 씁니다.
mqtt.subscribe(토픽)이 토픽의 메시지를 보내 달라고 등록. 접속이 끊겼다 다시 붙으면 구독도 사라지므로 접속 성공 직후에 합니다.
mqtt.publish(토픽, 글자)메시지 발행. 숫자는 snprintf로 글자(JSON)로 만들어 보냅니다.
mqtt.loop()받은 메시지를 처리하고 연결을 유지합니다. delay(5000)처럼 오래 멈추면 메시지를 늦게 받으므로 5초 간격은 millis()로 셉니다.

#include <PubSubClient.h>

#include "DHT.h"

const char* PREFIX = "aiot-kt2611";  // ← LAB 2-A와 같게
const char* ME     = "s01w";
const int LED = 2;                   // LED → GPIO2
DHT dht(15, DHT22);                  // DHT22 데이터 → GPIO15
Servo servo;                         // 서보 신호 → GPIO18
WiFiClient net;
PubSubClient mqtt(net);
bool ledOn = false;
int  deg   = 0;

String topic(const char* sub) { return String(PREFIX) + "/" + ME + "/" + sub; }

// 실제 상태를 알림. 마지막 true = retain (브로커가 마지막 값을 기억)
void reportState() {
  mqtt.publish(topic("led/state").c_str(), ledOn ? "ON" : "OFF", true);
  mqtt.publish(topic("servo/state").c_str(), String(deg).c_str(), true);
}

// 구독한 토픽에 명령이 오면 실행
void onMessage(char* t, byte* payload, unsigned int len) {
  String tp = t;
  String msg;
  for (unsigned int i = 0; i < len; i++) msg += (char)payload[i];
  msg.trim();
  Serial.println("[받음] " + tp + " : " + msg);

  if (tp == topic("led")) {                          // LED 명령 (휴대폰 시뮬레이터와 같은 규칙)
    String up = msg;
    up.toUpperCase();
    if (up == "ON" || up.startsWith("#")) ledOn = true;   // 색 코드는 "켜기"로
    else if (up == "OFF") ledOn = false;
    else if (up == "TOGGLE") ledOn = !ledOn;
    else return;                                     // 모르는 명령은 무시
    digitalWrite(LED, ledOn ? HIGH : LOW);
  } else if (tp == topic("servo")) {                 // 서보 명령: 0 ~ 180
    deg = constrain(msg.toInt(), 0, 180);            // 범위 밖 값은 잘라냄
    servo.write(deg);
  } else {
    return;
  }
  reportState();
}

void connectMqtt() {
  while (!mqtt.connected()) {
    String id = "esp32-" + String(random(0xffffff), HEX);
    Serial.print("MQTT 접속 시도 ... ");
    if (mqtt.connect(id.c_str())) {
      Serial.println("성공");
      mqtt.subscribe(topic("led").c_str());
      mqtt.subscribe(topic("servo").c_str());
      Serial.println("구독: " + topic("led") + ", " + topic("servo"));
      reportState();                                 // 접속하자마자 현재 상태부터 알림
    } else {
      Serial.print("실패, state=");
      Serial.println(mqtt.state());
      delay(2000);
    }
  }
}

void setup() {
  Serial.begin(115200);
  pinMode(LED, OUTPUT);
  servo.attach(18, 500, 2400);
  servo.write(0);
  dht.begin();
  WiFi.begin("Wokwi-GUEST", "", 6);
  Serial.print("Wi-Fi 연결 중");
  while (WiFi.status() != WL_CONNECTED) { delay(250); Serial.print("."); }
  Serial.println(" 연결됨");
  mqtt.setServer("broker.hivemq.com", 1883);
  mqtt.setCallback(onMessage);
}

void loop() {
  if (!mqtt.connected()) connectMqtt();
  mqtt.loop();                                       // 명령을 바로 받으려면 자주 불러야 함

  static unsigned long last = 0;
  if (millis() - last >= 5000) {                     // 5초마다 센서값 발행
    last = millis();
    float t = dht.readTemperature();
    float h = dht.readHumidity();
    if (isnan(t) || isnan(h)) return;
    char json[48];
    snprintf(json, sizeof json, "{\"temp\":%.1f,\"hum\":%.1f}", t, h);
    mqtt.publish(topic("sensor").c_str(), json);
  }
}

⑤ 확인 실험

  • 반응 속도 — 버튼을 누르고 LED가 켜질 때까지 얼마나 걸리나요? LAB 3의 ThingSpeak(20초 간격)와 비교해 봅니다. 보통 1초 안쪽입니다.
  • 새로고침해도 상태 유지 — 대시보드를 새로고침하면 LED 상태가 바로 다시 나옵니다. retain 덕분입니다. ESP32 코드의 true를 false로 바꾸면 어떻게 달라지는지 비교합니다.
  • ESP32가 꺼진 상태에서 명령 — Wokwi를 ■ 정지하고 ON을 누릅니다. 명령은 발행됐지만 상태는 바뀌지 않습니다. "눌렀다"와 "켜졌다"를 나눠 보여 줘야 하는 이유입니다.
  • PC와 휴대폰 동시에 — PC와 휴대폰에서 대시보드를 함께 열고 휴대폰에서 ON을 누르면 두 화면의 상태가 동시에 바뀝니다. 둘 다 같은 state 토픽을 구독하기 때문입니다.

안 될 때는 가운데(브로커)에서 양쪽을 봅니다. 웹 클라이언트나 MQTT Explorer로 aiot-kt2611/s01w/#을 구독해 두면 명령과 상태가 모두 보입니다. 명령이 안 보이면 대시보드 문제, 명령은 보이는데 상태가 안 오면 ESP32 문제입니다.

지금 대시보드에는 비밀번호가 없어서 토픽을 아는 사람은 누구나 내 LED와 서보를 움직일 수 있습니다. 문 잠금 · 히터 · 모터처럼 위험한 장치는 공개 브로커로 제어하지 않습니다. 바로 아래 IoT 보안에서 이 문제를 다룹니다.

from sklearn.ensemble import IsolationForest

# (1) z-score: 평균에서 표준편차 3배 이상 벗어나면 이상

from sklearn.linear_model import LinearRegression
from sklearn.metrics import mean_absolute_error

s = df["temp"].resample("1min").mean().interpolate()

# 최근 10분 값으로 10분 뒤 값을 예측
data = pd.DataFrame({f"lag{i}": s.shift(i) for i in range(10)})
data["target"] = s.shift(-10)
data = data.dropna()

split = int(len(data) * 0.8)          # 시간 순서대로 앞 80% 학습
train, test = data[:split], data[split:]
X_cols = [c for c in data.columns if c != "target"]

lr = LinearRegression().fit(train[X_cols], train["target"])
pred = lr.predict(test[X_cols])

print("AI 예측 오차(MAE):", mean_absolute_error(test["target"], pred))
print("'지금 값 그대로' 오차:", mean_absolute_error(test["target"], test["lag0"]))

import cv2, json, math, time
import mediapipe as mp
from mediapipe.tasks import python as mp_tasks
from mediapipe.tasks.python import vision
import paho.mqtt.client as mqtt

BROKER = "broker.hivemq.com"
PREFIX = "aiot-kt2611"   # 반 코드로 바꾸기
ME = "s01"               # 내 번호

def angle(a, b, c, w, h):
    """b를 꼭짓점으로 하는 a-b-c 각도(도). 화면 비율을 맞추려고 w, h를 곱한다."""
    v1 = ((a.x - b.x) * w, (a.y - b.y) * h)
    v2 = ((c.x - b.x) * w, (c.y - b.y) * h)
    cos = (v1[0] * v2[0] + v1[1] * v2[1]) / (math.hypot(*v1) * math.hypot(*v2) + 1e-6)
    return math.degrees(math.acos(max(-1.0, min(1.0, cos))))

options = vision.PoseLandmarkerOptions(
    base_options=mp_tasks.BaseOptions(model_asset_path="pose_landmarker_lite.task"),
    running_mode=vision.RunningMode.VIDEO)
landmarker = vision.PoseLandmarker.create_from_options(options)

client = mqtt.Client(mqtt.CallbackAPIVersion.VERSION2)
client.connect(BROKER, 1883)
client.loop_start()

cap = cv2.VideoCapture(0)
t0, last_send = time.time(), 0
while cap.isOpened():
    ok, frame = cap.read()
    if not ok:
        break
    h, w = frame.shape[:2]
    rgb = cv2.cvtColor(frame, cv2.COLOR_BGR2RGB)
    image = mp.Image(image_format=mp.ImageFormat.SRGB, data=rgb)
    result = landmarker.detect_for_video(image, int((time.time() - t0) * 1000))

    if result.pose_landmarks:
        lm = result.pose_landmarks[0]
        deg = angle(lm[12], lm[14], lm[16], w, h)   # 오른쪽 어깨-팔꿈치-손목
        for i in (12, 14, 16):
            cv2.circle(frame, (int(lm[i].x * w), int(lm[i].y * h)), 8, (0, 255, 0), -1)
        cv2.putText(frame, f"{deg:.0f} deg", (20, 50), cv2.FONT_HERSHEY_SIMPLEX, 1.5, (0, 255, 0), 3)

        if time.time() - last_send > 0.5:          # 0.5초마다 전송
            last_send = time.time()
            client.publish(f"{PREFIX}/{ME}/ai", json.dumps({"angle": round(deg)}))
            client.publish(f"{PREFIX}/{ME}/led", "ON" if deg < 60 else "OFF")

    cv2.imshow("pose", frame)
    if cv2.waitKey(1) & 0xFF == 27:   # ESC
        break

cap.release()
cv2.destroyAllWindows()

휴대폰 시뮬레이터는 https 페이지라서 암호화되지 않은 강의실 브로커에 접속할 수 없습니다. 이때는 ESP32와 PC만으로 진행하고, 라즈베리파이에 Mosquitto를 설치해 브로커로 씁니다. 모든 코드에서 BROKER를 라즈베리파이 IP(예: 192.168.0.10)로 바꾸면 나머지는 같습니다.

라즈베리파이
sudo apt install -y mosquitto mosquitto-clients
printf "listener 1883\nallow_anonymous true\n" | sudo tee /etc/mosquitto/conf.d/class.conf
sudo systemctl restart mosquitto

allow_anonymous true는 강의실 내부망 실습용 설정입니다. 외부에 공개되는 서버에서는 사용자 인증을 켭니다.

MISSION 03

보상을 바꿔 행동 바꾸기 ★ 오늘 오전의 핵심

Gymnasium 환경을 감싸(wrapper) 보상을 수정합니다. 짧게 학습시켜 행동이 달라지는지만 보면 됩니다.

import gymnasium as gym

class RewardTweak(gym.Wrapper):
    def step(self, action):
        obs, rew, term, trunc, info = self.env.step(action)
        # ① 에너지 페널티 — 토크를 적게 쓰게
        rew -= 0.1 * (action ** 2).sum()
        # ② 자세 페널티 — 몸통이 흔들리면 감점
        # rew -= 0.5 * abs(obs[1])
        return obs, rew, term, trunc, info
실험
  • 에너지 페널티를 넣으면 달리는 자세가 어떻게 바뀌나요?
  • 페널티 계수를 크게(1.0) 하면? — 아예 안 움직이지 않나요?
보상 해킹 (Reward Hacking)

"넘어지지 않으면 +1"이라고만 주면 로봇은 그냥 가만히 서 있습니다. 목표를 달성한 것이니 틀린 것도 아닙니다.
보상 설계 = 문제 정의 — 강화학습에서 가장 어려운 일입니다.

  • 실무 적용 시 추가로 필요한 것을 3가지 이상 적었다
과제 06

최종 프로젝트 제출

제출: 당일 17:00

6일간 배운 것을 하나로 묶어 만든 결과물을 제출합니다.

제출 항목

인식 · 판단 · 행동 중 몇 개를 담았는지 스스로 표시할 것

  1. 실행되는 코드 일체 (README 포함)
  2. 30~60초 시연 영상
  3. 5장 이내 발표자료
  4. 사용한 기술 요소 표시 (인식/판단/행동)
  5. 동작하지 않는 부분과 그 이유
  6. 실무에 적용한다면 무엇이 더 필요한지
제출 양식 예시
학번 / 이름 : 20261234 / 홍길동
주제 : ① 제스처 조종 로봇팔

기술 요소 : 인식(MediaPipe hands) ✓  판단(손가락 개수→모드 전환) ✓  행동(IK+그리퍼) ✓

동작하지 않는 부분
  - 손이 화면 밖으로 나가면 로봇팔이 마지막 좌표로 튐
  - 원인 : 랜드마크 미검출 시 이전 값을 그대로 쓰기 때문
  - 해결안 : 미검출 N프레임 이상이면 정지 상태로 전환

실무 적용 시 필요한 것
  - 좌표 스무딩(저역통과 필터), 작업 반경 밖 요청 거부, 비상 정지
채점 기준

5번과 6번에 배점이 있습니다. 완벽한 척하는 것보다 한계를 정확히 아는 것이 이 과정 6일간의 핵심 태도였습니다.

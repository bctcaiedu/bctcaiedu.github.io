# vibe70 — 바이브 코딩 × 하네스 엔지니어링 70시간 과정

Claude Code · Gemini CLI · Codex CLI 세 도구로 배우는 AI 에이전트 개발 과정입니다.
정적 강의 사이트이며, 일차마다 **강의 슬라이드(나레이션) · 실습 가이드 · 퀴즈** 3종이 생성됩니다.

> 지금은 **교안 틀** 상태입니다. 차시 제목·핵심 포인트·과제·기본 퀴즈는 채워져 있고,
> 슬라이드 설명·나레이션·실습 단계는 `TODO`로 표시되어 있습니다.

```
vibe70/
├── index.html          ← 과정 표지 (자동 생성)
├── nav.js              ← 공통 목차 사이드바 (DAYS 배열)
├── day1 ~ day10/
│   ├── index.html      ← 강의 슬라이드
│   ├── lab.html        ← 실습 가이드 (차시별 PART)
│   └── quiz.html       ← 퀴즈
└── _src/
    ├── build.js
    ├── day1.js ~ day10.js   ← 내용은 전부 여기에 있습니다
    ├── css/  deck.css · lab.css · quiz.css
    └── js/   deck.js · quiz.js
```

## 빌드

```bash
node _src/build.js        # 전체 일차 + 표지
node _src/build.js 3 5    # 3·5 일차만 다시 빌드
```

HTML을 직접 고치지 말고 **`_src/dayN.js`만 고친 뒤 다시 빌드**합니다.
사이드바 `nav.js`도 빌드할 때 `_src/js/nav.js` 템플릿과 각 일차의 차시 목록으로 자동 생성되므로 따로 고칠 필요가 없습니다.

## 디자인

`ubuntu2404` 강좌와 같은 분위기입니다. 왼쪽 사이드바(학습 진도 · 검색 · 접히는 일차 목록 · 다크 모드), 그라데이션 히어로 카드, 둥근 카드와 콜아웃, Pretendard 글꼴을 씁니다.

- 공통 색과 사이드바: `_src/css/theme.css` (색을 바꾸려면 `--accent`, `--accent2`, `--grad`만 고치면 됩니다)
- 페이지별: `_src/css/deck.css` · `lab.css` · `quiz.css`
- 학습 진도는 실습 가이드의 차시마다 있는 **완료로 표시** 버튼으로 기록되며, 각 학생의 브라우저(localStorage)에만 저장됩니다.
